# 優化理論模組 (optimization.md)

本模組實現了從基礎到進階的各種數值優化算法，涵蓋無約束優化、約束優化、線性規劃、二次規劃等核心內容。

---

## 1. 優化問題定義

**標準形式**：最小化目標函數

```
minimize  f(x)
subject to  x ∈ S
```

其中：
- `f : ℝⁿ → ℝ` 為目標函數（objective function）
- `S ⊆ ℝⁿ` 為可行域（feasible region）
- `x ∈ ℝⁿ` 為優化變數

**最大化問題**可通過 `minimize -f(x)` 轉換為最小化問題。

---

## 2. 梯度下降法 (Gradient Descent)

### 數學原理

梯度下降法是最基礎的無約束優化算法，利用函數梯度沿最陡下降方向迭代：

```
x_{n+1} = x_n - α∇f(x_n)
```

其中：
- `α > 0` 為學習率（learning rate）或步長（step size）
- `∇f(x_n)` 為目標函數在點 `x_n` 處的梯度

### 收斂性質

- **局部收斂性**：從任意初始點出發，在適當條件下收斂到局部極小值
- **收斂速度**：線性收斂（對強凸函數可達線性收斂率）
- **缺點**：對非凸曲面或病態條件可能收斂緩慢

### 實現說明

本模組使用**數值梯度**計算：

```python
grad ≈ (f(x + h) - f(x - h)) / (2h)
```

其中 `h = 1e-5` 為有限差分步長。

**代碼實現**：第 4-35 行

## 3. 牛頓法 (Newton's Method)

### 數學原理

牛頓法利用二階導數信息，收斂速度遠快於梯度下降：

```
x_{n+1} = x_n - H⁻¹∇f(x_n)
```

其中：
- `H = ∇²f(x_n)` 為**海森矩陣**（Hessian matrix），包含所有二階偏導數
- `H⁻¹` 為海森矩陣的逆矩陣

### 海森矩陣定義

對於 `n` 維函數，海森矩陣為 `n × n` 對稱矩陣：

```
H_{ij} = ∂²f / (∂x_i ∂x_j)
```

### 收斂性質

- **二次收斂**：在局部極小點附近具有二次收斂速度
- **條件要求**：需要海森矩陣正定（保證下降方向正確）
- **缺點**：需要計算/估計二階導數，計算量大

### 實現說明

本模組使用數值估計：

```python
f'(x) ≈ (f(x+h) - f(x-h)) / (2h)
f''(x) ≈ (f(x+h) - 2f(x) + f(x-h)) / h²
```

**代碼實現**：第 38-73 行

## 4. 擬牛頓法 (Quasi-Newton Methods)

### 數學原理

擬牛頓法只需計算梯度，用曲率信息近似海森矩陣或其逆，避免直接計算二階導數。

### BFGS 算法

BFGS（Broyden-Fletcher-Goldfarb-Shanno）是 最廣泛使用的擬牛頓法：

**迭代公式**：

```
H_{k+1} = H_k + (1 + y_k^T H_k y_k / s_k^T y_k) · (s_k s_k^T) / (s_k^T y_k)
          - (s_k y_k^T H_k + H_k y_k s_k^T) / (s_k^T y_k)
```

其中：
- `s_k = x_{k+1} - x_k`（位移向量）
- `y_k = ∇f_{k+1} - ∇f_k`（梯度差向量）
- `H_k` 為海森矩陣近似

**搜索方向**：`p_k = -H_k ∇f_k`

**代碼實現**：第 384-454 行

### L-BFGS 算法

有限內存 BFGS（Limited-memory BFGS）僅存儲最近 `m` 對 `(s_k, y_k)`，大幅降低記憶體需求：

```
p_k = -∑_{i=0}^{m-1} α_i y_{k-i}
```

其中 `α_i` 通過兩輪遞迴計算。

**代碼實現**：第 457-577 行

### 牛頓-拉夫森法 (Newton-Raphson)

多維牛頓法，使用數值海森矩陣計算：

```python
delta = -H⁻¹ ∇f(x)
x_new = x + α · delta
```

**代碼實現**：第 580-659 行

## 5. 凸優化 (Convex Optimization)

### 凸函數定義

若函數 `f` 滿足以下條件，則為**凸函數**：

```
f(λx + (1-λ)y) ≤ λf(x) + (1-λ)f(y)    ∀λ ∈ [0, 1]
```

幾何意義：函數圖像上任意兩點的弦位於函數圖像上方。

### 凸函數的關鍵性質

| 性質 | 說明 |
|------|------|
| 局部極小 = 全域極小 | 凸函數不存在局部極小值 |
| 海森矩陣半正定 | `∇²f(x) ≽ 0` |
| 一階條件 | `f(y) ≥ f(x) + ∇f(x)ᵀ(y - x)` |

### 判斷凸函數

1. **一元函數**：二階導數 `f''(x) ≥ 0`
2. **多元函數**：海森矩陣所有特徵值 `≥ 0`
3. **常见凸函數**：
   - 指數函數 `eᵃˣ`
   - 冪函數 `xᵃ`（`a ≥ 1`）
   - 負對數 `-log(x)`
   - 範數 `‖x‖`
   - 線性函數

## 6. 約束優化與拉格朗日乘數法

### 等式約束優化

**問題形式**：

```
minimize  f(x)
subject to  g_i(x) = 0,  i = 1, ..., m
```

### 拉格朗日函數

```
L(x, λ) = f(x) + Σ λ_i · g_i(x)
```

其中 `λ = (λ₁, ..., λ_m)` 為**拉格朗日乘子**。

### 極值條件

駐點條件（Stationary Condition）：

```
∇f(x*) + Σ λ_i · ∇g_i(x*) = 0
g_i(x*) = 0
```

**代碼實現**：第 136-193 行

### 增廣拉格朗日法 (Augmented Lagrange Method)

為改善數值穩定性，引入惩罚項：

```
L_aug = f(x) + Σ λ_i · g_i(x) + (ρ/2) · Σ g_i(x)²
```

其中 `ρ > 0` 為惩罚參數。

**代碼實現**：第 248-351 行

## 7. KKT 條件 (Karush-Kuhn-Tucker Conditions)

### 問題形式（含不等式約束）

```
minimize  f(x)
subject to  g_i(x) = 0,      i = 1, ..., m  (等式約束)
           h_j(x) ≤ 0,      j = 1, ..., p  (不等式約束)
```

### KKT 條件

若 `x*` 為局部極小值且滿足約束規範，則存在向量 `λ` 和 `μ` 使：

1. **駐點條件（Stationarity）**：
   ```
   ∇f(x*) + Σ λ_i ∇g_i(x*) + Σ μ_j ∇h_j(x*) = 0
   ```

2. **原始可行性（Primal Feasibility）**：
   ```
   g_i(x*) = 0,  h_j(x*) ≤ 0
   ```

3. **對偶可行性（Dual Feasibility）**：
   ```
   μ_j ≥ 0
   ```

4. **互補鬆弛條件（Complementary Slackness）**：
   ```
   μ_j · h_j(x*) = 0
   ```

### 幾何解釋

- `μ_j ≥ 0`：只有「活躍」的不等式約束（`h_j(x*) = 0`）才影響解
- `μ_j · h_j(x*) = 0`：要么約束活躍 (`h_j = 0`)，要么乘子為零（約束無影響）

## 8. 線性規劃 (Linear Programming)

### 標準形式

```
minimize  cᵀx
subject to  Ax = b
           x ≥ 0
```

其中：
- `c ∈ ℝⁿ` 為成本向量
- `A ∈ ℝ^{m×n}` 為約束矩陣
- `b ∈ ℝᵐ` 為約束邊界
- `x ∈ ℝⁿ` 為決策變數

### 單形法 (Simplex Method)

單形法通過在多面體頂點間移動來找到最優解：

1. 找到初始基本可行解
2. 檢查相鄰頂點是否能改善目標函數
3. 迭代直到無改善為止

### 內點法 (Interior-Point Method)

內點法通過穿越可行域內部來找到最優解，收斂時間為多項式時間。

### scipy 實現

本模組調用 `scipy.optimize.linprog`：

```python
result = linprog(c, A_ub=A, b_ub=b, method='highs')
```

**代碼實現**：第 354-381 行

## 9. 二次規劃 (Quadratic Programming)

### 問題形式

```
minimize  (1/2)xᵀHx + cᵀx
subject to  Ax ≤ b
           A_eq x = b_eq
           x ≥ 0
```

其中 `H` 為目標函數的二次項矩陣（通常要求正半定）。

### 應用場景

- 最小二乘法
- 支持向量機（SVM）
- 投資組合優化
- 模型預測控制（MPC）

### 共軛梯度法 (Conjugate Gradient Method)

用於求解 `Ax = b`，其中 `A` 為對稱正定矩陣：

```
α_k = (r_kᵀ r_k) / (p_kᵀ A p_k)
x_{k+1} = x_k + α_k p_k
r_{k+1} = r_k - α_k A p_k
β_k = (r_{k+1}ᵀ r_{k+1}) / (r_kᵀ r_k)
p_{k+1} = r_{k+1} + β_k p_k
```

**代碼實現**：第 76-133 行

## 10. 梯度上升法 (Gradient Ascent)

### 數學原理

梯度上升法用於**最大化**問題，是梯度下降法的對稱形式：

```
x_{n+1} = x_n + α∇f(x_n)
```

### 與梯度下降法的關係

- **最小化**：`x_{n+1} = x_n - α∇f(x_n)`
- **最大化**：`x_{n+1} = x_n + α∇f(x_n)`

實質上是將目標函數取負：`maximize f(x) ≡ minimize -f(x)`

### 應用場景

- 機率分佈的最大似然估計
- 機器學習中的損失函數最大化
- 信息論中的互信息最大化

## 11. 學習率 / 步長考慮

### 學習率選擇準則

學習率 `α` 的選擇直接影響收斂速度與穩定性：

| 學習率 | 表現 |
|--------|------|
| 過大 | 振盪發散或不穩定 |
| 過小 | 收斂緩慢 |
| 適中 | 穩定收斂 |

### 常見學習率策略

1. **固定學習率**：簡單但可能收斂慢
2. **衰減學習率**：`α_t = α₀ / (1 + t·decay)`
3. **動量法**：`v_{t+1} = βv_t + α∇f(x_t)`
4. **自適應學習率**（如 Adam）：根據梯度歷史自動調整

### 本模組實現策略

- **梯度下降**：固定學習率 `learning_rate`
- **BFGS/L-BFGS**：回溯線搜索（backtracking line search）
- **增廣拉格朗日**：自適應學習率調整
- **Levenberg-Marquardt**：阻尼參數動態調整

## 12. 約束處理方法

### 懲罰函數法 (Penalty Method)

將約束納入目標函數：

```
Φ(x) = f(x) + (μ/2) · Σ [max(0, g_i(x))]²
```

其中 `μ > 0` 為懲罰參數。


## 13. 非線性最小二乘與 Levenberg-Marquardt

### 問題形式

```
minimize  Σ r_i(x)²
```

其中 `r_i(x)` 為殘差函數。

### 高斯-牛頓法

```
J = ∂r_i/∂x  (雅可比矩陣)
Δx = -(JᵀJ)⁻¹ Jᵀ r
```

### Levenberg-Marquardt 算法

引入阻尼參數 `λ` 平衡高斯-牛頓與梯度下降：

```
(H + λ·diag(H)) · Δx = -Jᵀ r
```

其中 `H = JᵀJ`。

**特點**：
- `λ` 大 → 類似梯度下降（穩定）
- `λ` 小 → 類似高斯-牛頓（快速）

**代碼實現**：第 662-743 行

## 14. 算法比較總覽

| 算法 | 收斂速度 | 計算成本 | 記憶體需求 | 適用場景 |
|------|---------|---------|-----------|---------|
| 梯度下降 | 線性 | O(n) | O(n) | 大規模問題 |
| 牛頓法 | 二次 | O(n²) + 海森計算 | O(n²) | 小規模精確求解 |
| BFGS | 超線性 | O(n²) | O(n²) | 中等規模 |
