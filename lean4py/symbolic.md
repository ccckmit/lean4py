# 符號計算模組 (symbolic.py)

本模組基於 SymPy 庫，提供符號數學計算功能。

---

## 1. 符號表達式表示（AST）

符號表達式使用**抽象語法樹（Abstract Syntax Tree, AST）**表示：

```
表達式: x² + 2x + 1

AST 結構:
        (+)
       / | \
     (*)  (*)  1
    / \   / \
   x   2 x   x
```

- **節點類型**：運算符（`+`, `*`, `**`）、數值、常量、變量
- **葉節點**：符號變量（如 `x`, `y`）和常數（如 `1`, `2`）
- **內部節點**：運算操作

SymPy 內部使用 `sympy.Basic` 類層次結構表示所有表達式。

---

## 2. 符號操作：展開與因式分解

### 展開 (expand)

將嵌套運算展開為和的形式：

```
(x + 1)² → x² + 2x + 1
(x + y)(a + b) → ax + bx + ay + by
```

**數學原理**：應用分配律和冪的定義。

### 因式分解 (factor)

將多項式表示為不可約因式的乘積：

```
x² - 1 → (x - 1)(x + 1)
x³ + 3x² + 3x + 1 → (x + 1)³
```

**數學原理**：求多項式的根，將其表示為 `(x - r₁)(x - r₂)...` 形式。

## 3. 代數簡化規則

### 合并同類項

```
x + 2x + 3y → 3x + 3y
```

### 分數簡化

```
2x/x → 2（當 x ≠ 0）
```

### 指數規則

```
xᵃ · xᵇ → xᵃ⁺ᵇ
(xᵃ)ᵇ → xᵃʸ
```

### 分配規則

```
a·(b + c) → a·b + a·c
```

---

## 4. 多項式運算

### 多項式加法

同次項系數相加：

```
(2x² + 3x + 1) + (x² - x + 4) → 3x² + 2x + 5
```

### 多項式乘法

使用卷積原理，每項與每項相乘：

```
(x + 2)(x + 3) → x² + 5x + 6
```

### 多項式除法

```
(x³ + 2x² + x) ÷ (x + 1) → x² + x（餘 0）
```

---

## 5. 有理函數運算

有理函數為兩個多項式的商：`P(x)/Q(x)`

### 約分

```
(x² + x)/(x² - 1) = x/(x - 1)
```

### 通分

```
1/x + 1/y → (x + y)/(xy)
```

### 部分分式分解

```
1/(x² - 1) → 1/2·1/(x-1) - 1/2·1/(x+1)
```

## 6. 代數方程求解

### 線性方程

```
2x + 3 = 7 → x = 2
```

### 二次方程

使用求根公式：
```
ax² + bx + c = 0
x = (-b ± √(b²-4ac)) / 2a
```

### 高次方程

根據伽羅瓦理論，五次及以上一般無根式解。

### 方程組

```
{x + y = 5, 2x - y = 1} → x = 2, y = 3
```

## 7. 符號微分

### 基本規則

| 函數類型 | 求導規則 |
|---------|---------|
| xⁿ | nxⁿ⁻¹ |
| sin(x) | cos(x) |
| cos(x) | -sin(x) |
| eˣ | eˣ |
| ln(x) | 1/x |
| f(g(x)) | f'(g(x))·g'(x)（鏈式法則） |

### 偏導數

對多元函數 f(x, y, z) 求偏導：
```
∂/∂x (x²y + xyz) = 2xy + yz
```

---

## 8. 符號積分

### 基本規則

| 函數類型 | 積分結果 |
|---------|---------|
| xⁿ | xⁿ⁺¹/(n+1)（n ≠ -1）|
| 1/x | ln|x| |
| eˣ | eˣ |
| sin(x) | -cos(x) |
| cos(x) | sin(x) |

### 不定積分與常數 C

```
∫ f(x) dx = F(x) + C
```

### 定積分

```
∫ₐᵇ f(x) dx = F(b) - F(a)
```

### 常見限制

- 有理函數：恆可積
- 指數/三角函數：恆可積
- 橢圓積分：無封閉形式
- f(x) = e^(x²)：無初等原函數

## API 參考

### `symbolic_derivative(expr_str, var='x')`

計算符號導數：

```python
symbolic_derivative("x**2 + 3*x", "x")  # → "2*x + 3"
symbolic_derivative("sin(x)", "x")       # → "cos(x)"
```

### `symbolic_integral(expr_str, var='x')`

計算符號積分（不定積分）：

```python
symbolic_integral("x**2", "x")  # → "x**3/3 + C"
```

### `symbolic_simplify(expr_str)`

代數簡化：

```python
symbolic_simplify("x**2 + 2*x**2 + 3*x")  # → "3*x**2 + 3*x"
```
