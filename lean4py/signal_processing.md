# 信号处理模块 (signal_processing)

本模块实现了数字信号处理中的核心算法，包括离散傅里叶变换（DFT）、快速傅里叶变换（FFT）、频谱分析及时频分析。

---

## 1. 离散时间信号与系统

### 1.1 离散时间信号

离散时间信号是定义在整数时间索引 n 上的序列，记为 x[n]，其中 n ∈ ℤ。常见的离散信号包括：

- **单位冲激序列**: δ[n] = {1, n=0; 0, n≠0}
- **单位阶跃序列**: u[n] = {1, n≥0; 0, n<0}
- **正弦序列**: x[n] = A·cos(2πfn + φ)

### 1.2 离散时间系统

离散时间系统对输入信号 x[n] 进行变换产生输出 y[n]，记为：

```
y[n] = T{x[n]}
```

---

## 2. 线性时不变系统 (LTI)

### 2.1 线性系统

若系统满足叠加原理，则为线性系统：

```
T{ax₁[n] + bx₂[n]} = aT{x₁[n]} + bT{x₂[n]}
```

### 2.2 时不变系统

若系统特性不随时间变化：

```
y[n] = T{x[n]}  ⇒  y[n-k] = T{x[n-k]}
```

### 2.3 LTI 系统的特性

LTI 系统具有两个重要性质：
- **卷积运算**：y[n] = x[n] * h[n]
- **复指数信号是特征函数**：e^(jωn) 输入产生 H(e^(jω))·e^(jωn) 输出

---

## 3. 卷积 (Convolution)

### 3.1 定义

两个序列的卷积定义为：

```
y[n] = x[n] * h[n] = Σ(k=-∞ to ∞) x[k] · h[n-k]
```

### 3.2 卷积的性质

| 性质 | 表达式 |
|------|--------|
| 交换律 | x[n] * h[n] = h[n] * x[n] |
| 结合律 | (x * h) * g = x * (h * g) |
| 分配律 | x * (h + g) = x * h + x * g |

### 3.3 计算方法

卷积可以通过"翻转-移位-相乘-求和"四步完成。对于长度为 N 和 M 的序列，卷积结果长度为 N+M-1。

---

## 4. Z 变换

### 4.1 定义

序列 x[n] 的 Z 变换定义为：

```
X(z) = Σ(n=-∞ to ∞) x[n] · z^(-n)
```

### 4.2 收敛域 (ROC)

Z 变换的收敛域取决于序列特性：
- **有限长度序列**：除 z=0 或 z=∞ 外整个复平面
- **右边序列**：|z| > r₁（外部区域）
- **左边序列**：|z| < r₂（内部区域）
- **双边序列**：r₁ < |z| < r₂（环形区域）

### 4.3 Z 变换的重要性质

| 性质 | 时域 | Z 域 |
|------|------|------|
| 线性 | ax₁[n] + bx₂[n] | aX₁(z) + bX₂(z) |
| 时移 | x[n-k] | z^(-k)X(z) |
| 卷积 | x[n] * h[n] | X(z)·H(z) |

---

## 5. 传递函数 H(z)

### 5.1 定义

对于 LTI 系统，传递函数定义为输出与输入 Z 变换之比：

```
H(z) = Y(z) / X(z)
```

### 5.2 频率响应

令 z = e^(jω)，得到系统的频率响应：

```
H(e^(jω)) = |H(e^(jω))| · e^(j∠H(ω))
```

- **幅频响应**：|H(e^(jω))|
- **相频响应**：∠H(ω)

### 5.3 因果性条件

因果 LTI 系统的传递函数必须满足：
- 分子阶数 ≤ 分母阶数
- 收敛域包含单位圆 |z| = 1

## 6. FIR 与 IIR 滤波器

### 6.1 FIR 滤波器 (有限脉冲响应)

**差分方程**：
```
y[n] = Σ(k=0 to M) bₖ · x[n-k]
```

**特点**：
- 脉冲响应 h[n] 长度为 M+1，有限长度
- 总是稳定的
- 可以实现线性相位
- 计算复杂度较高

**传递函数**：
```
H(z) = Σ(k=0 to M) bₖ · z^(-k)
```

### 6.2 IIR 滤波器 (无限脉冲响应)

**差分方程**：
```
y[n] = Σ(k=0 to M) bₖ · x[n-k] - Σ(k=1 to N) aₖ · y[n-k]
```

**特点**：
- 脉冲响应理论上无限长
- 可能不稳定
- 通常非线性相位
- 计算效率高

**传递函数**：
```
H(z) = Σ(k=0 to M) bₖ·z^(-k) / (1 + Σ(k=1 to N) aₖ·z^(-k))
```

### 6.3 比较

| 特性 | FIR | IIR |
|------|-----|-----|
| 稳定性 | 绝对稳定 | 可能不稳定 |
| 相位 | 线性相位可选 | 通常非线性 |
| 阶数 | 较高 | 较低 |
| 设计方法 | 窗口法、频率抽样法 | 巴特沃斯、切比雪夫 |

## 7. 离散傅里叶变换 (DFT)

### 7.1 定义

长度为 N 的序列 x[n] 的 DFT 定义为：

```
X[k] = Σ(n=0 to N-1) x[n] · e^(-j2πkn/N),  k = 0, 1, ..., N-1
```

### 7.2 逆 DFT (IDFT)

```
x[n] = (1/N) · Σ(k=0 to N-1) X[k] · e^(j2πkn/N),  n = 0, 1, ..., N-1
```

### 7.3 DFT 矩阵表示

DFT 可以表示为矩阵运算：

```
X = W · x
```

其中 W 是 N×N 的 DFT 矩阵，元素 W[k,n] = e^(-j2πkn/N)。

### 7.4 频率分辨率

DFT 的频率分辨率为：

```
Δf = fs / N
```

其中 fs 是采样率，N 是 DFT 长度。

### 7.5 本模块实现

```python
def dft(x: List[float]) -> List[complex]:
    n = len(x)
    result = []
    for k in range(n):
        coeff = 0j
        for i in range(n):
            angle = -2 * math.pi * k * i / n
            coeff += x[i] * cmath.exp(complex(0, angle))
        result.append(coeff)
    return result
```

**时间复杂度**：O(N²)

## 8. 快速傅里叶变换 (FFT)

### 8.1 Cooley-Tukey 算法原理

FFT 通过分治策略将 DFT 的计算复杂度从 O(N²) 降低到 O(N log N)。

### 8.2 基-2 DIT FFT（时间抽取法）

**前提条件**：序列长度 N 必须是 2 的幂次。

**分解过程**：
1. 将序列分为偶数索引和奇数索引两组
2. 对两组分别递归计算 DFT
3. 通过"蝴蝶"运算合并结果

**蝴蝶运算**：
```
even[k]     →  result[k]       = even[k] + W^k · odd[k]
                  result[k+N/2] = even[k] - W^k · odd[k]
```

其中 W = e^(-j2π/N) 是旋转因子。

### 8.3 递归实现

```python
def _fft_recursive(x: List[complex]) -> List[complex]:
    n = len(x)
    if n <= 1:
        return x
    
    even = _fft_recursive([x[i] for i in range(0, n, 2)])
    odd = _fft_recursive([x[i] for i in range(1, n, 2)])
    
    result = [0j] * n
    for k in range(n // 2):
        angle = -2 * math.pi * k / n
        twiddle = cmath.exp(complex(0, angle)) * odd[k]
        result[k] = even[k] + twiddle
        result[k + n // 2] = even[k] - twiddle
    
    return result
```

### 8.4 FFT vs DFT 复杂度

| 算法 | 复杂度 | N=1024 时的运算次数 |
|------|--------|---------------------|
| DFT | O(N²) | ~1,048,576 |
| FFT | O(N log N) | ~10,240 |

### 8.5 逆 FFT (IFFT)

IFFT 可以通过以下步骤实现：
1. 对输入序列取共轭
2. 执行 FFT
3. 对结果取共轭并除以 N

```python
def ifft(X: List[complex]) -> List[float]:
    X_conj = [x.conjugate() for x in X]
    result_complex = _fft_recursive(X_conj)
    n = len(X)
    result = [x.conjugate().real / n for x in result_complex]
    return result
```

## 9. 滤波器设计

### 9.1 窗口法设计 FIR 滤波器

**设计步骤**：
1. 根据指标确定理想低通滤波器频率响应 Hd(e^(jω))
2. 计算理想脉冲响应 hd[n]
3. 截断（加窗）：h[n] = hd[n] · w[n]

**常用窗函数**：

| 窗函数 | 主瓣宽度 | 旁瓣衰减 |
|--------|----------|----------|
| 矩形窗 | 4π/N | -13 dB |
| 汉宁窗 | 8π/N | -31 dB |
| 汉明窗 | 8π/N | -41 dB |
| 布莱克曼窗 | 12π/N | -57 dB |

**矩形窗的影响**：
- 主瓣变宽导致过渡带变宽
- 吉布斯现象导致肩峰

### 9.2 双线性变换法设计 IIR 滤波器

**变换公式**：
```
s = (2/T) · (1 - z^(-1)) / (1 + z^(-1))
```

或
```
z = (1 + sT/2) / (1 - sT/2)
```

**设计步骤**：
1. 确定模拟滤波器的规格（通带、阻带、过渡带宽）
2. 设计模拟原型滤波器（巴特沃斯、切比雪夫等）
3. 进行频率预畸变
4. 应用双线性变换得到数字滤波器

### 9.3 频率变换

从低通滤波器原型可以变换为其他类型：
- 低通 → 高通：z → -z^(-1)
- 低通 → 带通：复杂变换
- 低通 → 带阻：复杂变换

## 10. 本模块函数说明

### 10.1 核心函数

| 函数 | 说明 |
|------|------|
| `dft(x)` | 离散傅里叶变换，O(N²) 复杂度 |
| `idft(X)` | 离散傅里叶逆变换 |
| `fft(x)` | 快速傅里叶变换，O(N log N) 复杂度，自动补零至 2 的幂次 |
| `ifft(X)` | 快速傅里叶逆变换 |

### 10.2 分析函数

| 函数 | 说明 |
|------|------|
| `spectrogram(x, window_size, overlap)` | 短时傅里叶变换（STFT），返回功率谱 |
| `compute_frequency_spectrum(x, sample_rate)` | 计算信号频率谱，返回频率轴和幅度谱 |

### 10.3 使用示例

**FFT 频谱分析**：
```python
import signal_processing as sp

x = [0, 1, 2, 3, 2, 1, 0, 1]  # 输入信号
spectrum = sp.fft(x)           # 计算 FFT
freqs, mags = sp.compute_frequency_spectrum(x, sample_rate=1000)
```

**语谱图**：
```python
import signal_processing as sp

x = [信号序列]
spec = sp.spectrogram(x, window_size=256, overlap=128)
```

## 11. 数学基础总结

### 11.1 核心公式速查

```
卷积:      y[n] = Σ x[k]·h[n-k]
Z变换:     X(z) = Σ x[n]·z^(-n)
传递函数:  H(z) = Y(z)/X(z)
DFT:       X[k] = Σ x[n]·e^(-j2πkn/N)
FFT:       分治策略，O(N log N)
```

### 11.2 关键定理

- **帕塞瓦尔定理**：信号能量在时域和频域守恒
- **采样定理**：fs ≥ 2fm 才能无失真重建
- **卷积定理**：时域卷积等于频域乘积
