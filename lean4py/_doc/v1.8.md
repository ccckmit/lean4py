# lean4py v1.8 Release Notes

## New Features

### Reinforcement Learning (`reinforcement_learning.py` - new module)
- `QLearning` - Q-learning agent for discrete state/action spaces
- `SARSA` - SARSA (State-Action-Reward-State-Action) learning
- `epsilon_greedy()` - Epsilon-greedy action selection
- `run_episode()` - Run agent in environment

### Gaussian Process (`gaussian_process.py` - new module)
- `GaussianProcessRegressor` - Gaussian process regression with RBF kernel
- `rbf_kernel()` - Radial basis function kernel
- `predict_gp()` - Predict with uncertainty estimates

### Optimization (`optimization.py` extended)
- `newton_raphson()` - Newton-Raphson method for root finding (extended from optimization)
- `levenberg_marquardt()` - Levenberg-Marquardt algorithm for nonlinear least squares

### Statistics (`statistics.py` extended)
- `mann_kendall()` - Mann-Kendall trend test
- `wilcoxon_signed_rank()` - Wilcoxon signed-rank test
- `wilcoxon_rank_sum()` - Wilcoxon rank-sum test (alternative to Mann-Whitney U)

## Test Coverage
