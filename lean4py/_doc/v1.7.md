# lean4py v1.7 Release Notes

## New Features

### Machine Learning (`ml_basics.py` extended)
- `kmeans()` - K-means clustering algorithm
- `random_forest()` - Random forest classifier (multiple decision trees)
- `predict_random_forest()` - Prediction using random forest

### Dimensionality Reduction (`linear_algebra.py` extended)
- `pca()` - Principal Component Analysis for dimensionality reduction
- `compute_covariance_matrix()` - Compute covariance matrix of data

### Signal Processing (`signal_processing.py` - new module)
- `dft()` - Discrete Fourier Transform
- `idft()` - Inverse Discrete Fourier Transform
- `fft()` - Fast Fourier Transform (Cooley-Tukey algorithm)
- `ifft()` - Inverse FFT
- `spectrogram()` - Simple spectrogram computation

### Optimization (`optimization.py` extended)
- `bfgs()` - BFGS quasi-Newton optimization method
- `lbfgs()` - Limited-memory BFGS (L-BFGS)
