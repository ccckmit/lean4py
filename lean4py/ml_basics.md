# Machine Learning Basics - 機器學習基礎

本文件基於 `ml_basics.py` 模組，詳細解釋機器學習背后的數學原理。

---

## 1. 監督式學習 vs 無監督式學習

### 監督式學習 (Supervised Learning)

監督式學習的核心思想是：**從已標註的訓練數據中學習輸入到輸出的映射關係**。

訓練數據的形式為：(輸入特徵, 正確輸出標籤)，演算法通過最小化預測誤差來調整模型參數。

**典型應用場景：**
- 圖像分類（貓 vs 狗）
- 郵件spam檢測
- 房價預測

本模組中的 `linear_regression_ml`、`logistic_regression`、`svm_linear`、`decision_tree`、`random_forest` 都屬於監督式學習。

### 無監督式學習 (Unsupervised Learning)

無監督式學習的訓練數據**沒有標籤**，演算法需要自己發現數據中的結構和模式。

**典型應用場景：**
- 客戶分群
- 異常檢測
- 數據壓縮

本模組中的 `kmeans` 演算法就是典型的無監督學習，用於將數據自動分組為 k 個簇。

## 2. 分類 vs 回歸

### 分類問題 (Classification)

分類問題的輸出是**離散的類別標籤**。例如：
- 郵件：「垃圾郵件」或「正常郵件」（二分類）
- 水果：「蘋果」、「橘子」、「香蕉」（多分類）

本模組中的 `logistic_regression`（二分類）、`decision_tree`、`random_forest` 都是分類演算法。

### 回歸問題 (Regression)

回歸問題的輸出是**連續的數值**。例如：
- 房價預測：$150,000 ~ $500,000
- 溫度預測：15.5°C ~ 32.8°C

本模組中的 `linear_regression_ml` 解決的就是回歸問題，預測連續值輸出。

## 3. 感知機學習規則 (Perceptron Learning Rule)

感知機是最簡單的神經網絡基本單元，由 Frank Rosenblatt 於 1957 年提出。

### 數學模型

對於輸入向量 $\mathbf{x} = (x_1, x_2, ..., x_n)$，感知機計算：

$$z = \sum_{i=1}^{n} w_i x_i + b$$

$$y = \begin{cases} 1 & \text{if } z \geq 0 \\ 0 & \text{if } z < 0 \end{cases}$$

### 感知機學習規則

當預測錯誤時，更新權重：

$$w_i \leftarrow w_i + \eta \cdot (y_{true} - y_{pred}) \cdot x_i$$

其中 $\eta$ 是學習率。

**收斂定理：** 如果數據線性可分，感知機保證在有限步數內收斂。

本模組的 SVM 線性分類器 `svm_linear` 使用了類似的梯度更新思想，但採用了hinge loss。

## 4. 邏輯回歸與 Sigmoid 函數

### 為什麼需要 Sigmoid？

線性回歸的輸出是 $(-\infty, +\infty)$，無法直接用於分類概率。Sigmoid 函數將任意實數映射到 $(0, 1)$ 區間：

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

### 邏輯回歸的損失函數

對於二分類問題，使用交叉熵損失：

$$L(\mathbf{w}) = -\frac{1}{n} \sum_{i=1}^{n} \left[ y_i \log(p_i) + (1-y_i) \log(1-p_i) \right]$$

其中 $p_i = \sigma(\mathbf{w}^T \mathbf{x}_i + b)$

### 梯度推導

對損失函數求導得到簡潔的梯度形式：

$$\frac{\partial L}{\partial w_j} = \frac{1}{n} \sum_{i=1}^{n} (p_i - y_i) x_{ij}$$

本模組的 `logistic_regression` 函數使用梯度上升（注意代碼中是加法）來最大化對數似然。

## 5. K 近鄰演算法 (K-Nearest Neighbors)

### 基本思想

「物以類聚」——一個樣本的類別由其最近的 K 個鄰居決定。

### 演算法步驟

1. 計算待預測樣本與所有訓練樣本的距離
2. 找出距離最近的 K 個樣本
3. 根據 K 個鄰居的類別進行投票（多數表決）

### 距離度量

本模組使用歐幾里得距離：

$$d(\mathbf{a}, \mathbf{b}) = \sqrt{\sum_{i=1}^{n} (a_i - b_i)^2}$$

### K 的選擇

- **K 過小**：對噪聲敏感，容易過擬合
- **K 過大**：可能包含其他類別的樣本，欠擬合

KNN 的計算複雜度為 $O(n)$$，適合小數據集。

## 6. 決策樹與信息增益

### 決策樹結構

決策樹通過遞歸地劃分特徵空間來構建：
- **內部節點**：特徵測試（如 $x_1 \leq 0.5$）
- **分支**：測試結果
- **葉節點**：類別標籤

### CART 演算法

本模組使用 CART（Classification and Regression Tree）演算法，每次選擇最佳特徵和閾值進行分割。

### 基尼不純度 (Gini Impurity)

$$Gini(S) = 1 - \sum_{c} p_c^2$$

其中 $p_c$ 是類別 $c$ 在集合 $S$ 中的比例。

基尼不純度衡量的是從集合中隨機抽取兩個樣本，它們類別不一致的概率。**值越小表示集合越純淨**。

### 信息增益 (Information Gain)

$$IG(S, feature) = Gini(S) - \frac{|S_{left}|}{|S|} Gini(S_{left}) - \frac{|S_{right}|}{|S|} Gini(S_{right})$$

CART 演算法選擇**信息增益最大**的特徵和閾值進行分割。

本模組的 `decision_tree` 函數使用貪心策略，遍歷所有特徵和可能的閾值，選擇基尼不純度加權和最小的分割。

### 隨機森林 (Random Forest)

為什麼需要隨機森林？
- 單棵決策樹容易過擬合
- 對數據噪聲敏感

隨機森林通過兩種隨機性構建多棵樹：
1. **樣本自助抽樣** (Bootstrap sampling)：每棵樹用部分樣本訓練
2. **特徵隨機選擇**：每個節點只考虑隨機選擇的特徵子集

最終預測通過**多數投票**產生，提高整體穩定性。

本模組的 `random_forest` 函數实现了這一思想，`predict_random_forest` 進行投票預測。

## 7. K-Means 聚類

### 目標

將 n 個數據點劃分為 K 個簇，使得簇內方差最小化：

$$\min_{\mathbf{C}_1, ..., \mathbf{C}_K} \sum_{k=1}^{K} \sum_{\mathbf{x} \in C_k} \|\mathbf{x} - \mathbf{\mu}_k\|^2$$

其中 $\mathbf{\mu}_k$ 是簇 k 的中心。

### 演算法流程

1. **初始化**：隨機選擇 K 個數據點作為初始簇中心
2. **分配**：將每個樣本分配給最近的簇中心
3. **更新**：重新計算每個簇的中心（均值）
4. **重複**：直到收斂或達到最大迭代次數

### 局部最優

K-Means 對初始簇中心敏感。本模組的 `kmeans` 函數通过 `n_init=10` 多次運行，選擇慣性（inertia）最小的結果。

### 收斂判斷

當樣本的簇分配不再變化時，演算法收斂。嚴格收斂需要保證所有簇中心不再移動。

## 8. 偏差-方差權衡 (Bias-Variance Tradeoff)

### 定義

對於任意機器學習模型，其預測誤差可以分解為：

$$\text{Err}(\mathbf{x}) = \text{Bias}^2 + \text{Variance} + \text{Irreducible Error}$$

### 偏差 (Bias)

偏差衡量模型**長期預測值與真實值的偏離程度**。

高偏差 = 欠擬合（Underfitting）
- 模型太簡單，無法捕捉數據的複雜結構
- 訓練誤差和測試誤差都較高

### 方差 (Variance)

方差衡量模型**對數據變化的敏感程度**。

高方差 = 過擬合（Overfitting）
- 模型太複雜，對訓練數據的噪聲也進行擬合
- 訓練誤差低，但測試誤差高

### 權衡視覺化

```
        │                     │
  測試誤差│                ╭──╮
        │               ╭─╯  ╰─╮
        │              ╭╯       ╰╮
        │             ╭╯         ╰╮
        │    ╭───────╯            ╰────  (過擬合區域)
        │   ╭╯  (最優複雜度)
        │  ╭╯
        │ ╭╯
        │╭╯
        └─────────────────────────────
              模型複雜度 →
```

### 實際應用

| 方法 | 降低偏差 | 降低方差 |
|------|----------|----------|
| 增加模型複雜度 | ✓ | ✗ |
| 增加訓練數據 | - | ✓ |
| 正則化 | ✓ | ✓ |
| 集成學習（隨機森林） | - | ✓ |

本模組的 `decision_tree` 中的 `max_depth` 參數控制了樹的深度，決定了模型的複雜度：
- 深度過大 → 高方差（過擬合）
- 深度過小 → 高偏差（欠擬合）

`random_forest` 通过集成多棵樹，有效降低了單棵樹的高方差問題。
