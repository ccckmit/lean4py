# 证明论 (Proof Theory)

## 概述

证明论是数理逻辑的四大分支之一，研究证明的形式结构和性质。本模块实现 `proof_theory.py`，模仿 mathlib4 的 `Mathlib.Logic.ProofTheory`，涵盖矢列式（sequents）、切消除（cut elimination）等核心概念。

---

## 1. 逻辑联结词与逻辑公理

### 1.1 命题逻辑联结词

| 联结词 | 符号 | 含义 |
|--------|------|------|
| 否定 | ¬ | 非 |
| 合取 | ∧ | 且 |
| 析取 | ∨ | 或 |
| 蕴含 | → | 如果...则... |
| 等价 | ↔ | 当且仅当 |

### 1.2 逻辑公理系统

经典命题逻辑的公理系统通常包含以下公理模式：

- **恒等律**: `A → A`
- **蕴含消去**: `(A → B) → (A → B)`（简化的表达）
- **双重否定律**: `¬¬A → A`

公理系统确保推理的可靠性和完备性。

## 2. 自然演绎：引入规则与消去规则

### 2.1 自然演绎系统

自然演绎（Natural Deduction）由根岑（Gentzen）提出，通过引入规则（Introduction Rules）和消去规则（Elimination Rules）来表达证明。

### 2.2 联结词的规则

#### 合取 (∧)

| 规则类型 | 名称 | 形式 |
|----------|------|------|
| 引入 | ∧-intro | 从 A 和 B 推出 A ∧ B |
| 消去左 | ∧-elim₁ | 从 A ∧ B 推出 A |
| 消去右 | ∧-elim₂ | 从 A ∧ B 推出 B |

#### 析取 (∨)

| 规则类型 | 名称 | 形式 |
|----------|------|------|
| 引入左 | ∨-intro₁ | 从 A 推出 A ∨ B |
| 引入右 | ∨-intro₂ | 从 B 推出 A ∨ B |
| 消去 | ∨-elim | 从 A ∨ B、A → C、B → C 推出 C |

#### 蕴含 (→)

| 规则类型 | 名称 | 形式 |
|----------|------|------|
| 引入 | →-intro | 从假设 A 导出 B，则得到 A → B |
| 消去 | →-elim | 从 A 和 A → B 推出 B（分离规则） |

#### 否定 (¬)

| 规则类型 | 名称 | 形式 |
|----------|------|------|
| 引入 | ¬-intro | 从 A 导出 ⊥（矛盾），则得到 ¬A |
| 消去 | ¬-elim | 从 ¬A 和 A 推出 ⊥ |

### 2.3 否定即蕴含

在某些形式化中，`¬A` 等价于 `A → ⊥`，这使得否定规则可以通过蕴含规则统一处理。

## 3. 矢列演算：矢列 Γ ⊢ Δ

### 3.1 矢列的定义

矢列（Squent）是形如 `Γ ⊢ Δ` 的结构，其中：
- `Γ`（左方）是**前件**（antecedent），表示假设集合
- `Δ`（右方）是**后件**（consequent），表示结论集合
- `⊢` 表示"推出"关系

矢列 `Γ ⊢ Δ` 语义上表示：**在假设 Γ 下，可以推出结论 Δ 中的至少一个公式**。

### 3.2 矢列演算的推理规则

#### 结构规则

- **弱化规则（Weakening）**：
  - 左弱化：`Γ ⊢ Δ ⇒ Γ, A ⊢ Δ`
  - 右弱化：`Γ ⊢ Δ ⇒ Γ ⊢ Δ, A`

- **收缩规则（Contraction）**：
  - 左收缩：`Γ, A, A ⊢ Δ ⇒ Γ, A ⊢ Δ`
  - 右收缩：`Γ ⊢ Δ, A, A ⇒ Γ ⊢ Δ, A`

- **交换规则（Exchange）**：允许重新排列前件或后件的顺序

#### 逻辑规则

| 联结词 | 左规则（引入前件） | 右规则（引入后件） |
|--------|-------------------|-------------------|
| A ∧ B | 从 Γ, A, B ⊢ Δ 推出 Γ, A ∧ B ⊢ Δ | 从 Γ ⊢ Δ, A 和 Γ ⊢ Δ, B 推出 Γ ⊢ Δ, A ∧ B |
| A ∨ B | 从 Γ, A ⊢ Δ 和 Γ, B ⊢ Δ 推出 Γ, A ∨ B ⊢ Δ | 从 Γ ⊢ Δ, A, B 推出 Γ ⊢ Δ, A ∨ B |
| A → B | 从 Γ ⊢ Δ, A 和 Γ, B ⊢ Δ 推出 Γ, A → B ⊢ Δ | 从 Γ, A ⊢ Δ, B 推出 Γ ⊢ Δ, A → B |
| ¬A | 从 Γ ⊢ Δ, A 推出 Γ, ¬A ⊢ Δ | 从 Γ, A ⊢ Δ 推出 Γ ⊢ Δ, ¬A |

### 3.3 Sequents 类

```python
class Sequent:
    """矢列 Γ ⇒ Δ"""
    
    def __init__(self, antecedent: List[str], consequent: List[str]):
        self.antecedent = antecedent  # Γ
        self.consequent = consequent   # Δ
```

矢列的核心操作：
- `is_valid(seq)`: 检验矢列是否有效（语义有效性）
- `from_formula(phi)`: 将单公式 φ 转换为矢列 `⇒ φ`

## 4. 切消除定理

### 4.1 切规则

**切规则（Cut Rule）** 是矢列演算中的一个重要规则：

```
Γ ⊢ Δ, A    A, Σ ⊢ Π
─────────────────────  (Cut)
   Γ, Σ ⊢ Δ, Π
```

切规则的含义是：如果我们能从假设集 Γ 推出某个公式 A（或在 Δ 中），并且能从 A 出发推出结论，那么可以直接从 Γ 推出 Δ 中的结论，而不需要显式使用 A。

### 4.2 切消除定理

**切消除定理（Cut Elimination Theorem）** 是证明论中最深刻的结果之一，由根岑在 1934 年证明：

> **定理**：任何一个可以用矢列演算证明的命题，都存在一个**不使用切规则**的证明。

### 4.3 切消除的重要性

1. **子公式性质**：无切证明中出现的公式都是原证明结论的子公式
2. **可判定性**：无切证明的结构更简单，便于机械化验证
3. **一致性证明**：切消除可以用来证明系统的一致性
4. **局部性**：证明的正确性可以局部检查

### 4.4 CutElimination 类

```python
class CutElimination:
    """切消除定理：每个证明都可以无切"""
    
    @staticmethod
    def holds() -> bool:
        """切消除成立（简化）"""
        return True
    
    @staticmethod
    def eliminate(proof: List['Sequent']) -> List['Sequent']:
        """从证明中消除切（简化）"""
        return proof
```

## 5. 一致性证明

### 5.1 一致性的定义

一个理论 T 是一致的，当且仅当不存在公式 φ，使得 T 既证明 φ 又证明 ¬φ。等价地：

$$T \nvdash \bot$$

即 T 不能推出矛盾（⊥）。

### 5.2 一致性的重要性

一致性是理论可靠性的基本要求。如果一个理论不一致，它可以推出任意公式，从而失去意义。

### 5.3 哥德尔不完备定理与一致性

**第一不完备定理**：任何包含皮亚诺算术（PA）的递归可枚举理论，如果是一致的，就是不完备的。

**第二不完备定理**：一个足够强的理论（如 PA）不能证明自身的一致性：

$$PA \nvdash Con(PA)$$

其中 `Con(PA)` 表示 PA 的一致性陈述。

### 5.4 Consistency 类

```python
class Consistency:
    """理论的一致性"""
    
    @staticmethod
    def is_consistent(theory: str) -> bool:
        """T ⊬ ⊥（简化）"""
        return True
    
    @staticmethod
    def godel_second_theorem() -> bool:
        """PA ⊬ Con(PA)（简化：成立）"""
        return True
```

## 6. 正规化与子公式性质

### 6.1 证明的正规化

正规化（Normalization）是将证明转换为**正规形式**的过程。正规形式的特点是不存在可以进行进一步归约的主项（redex）。

### 6.2 归约规则

在自然演绎中，主要的归约规则包括：

- **β-归约**（用于蕴含消去）：
  ```
  (λx. M) N  ⟶  M[x := N]
  ```
  对应于：给定 A → B 的证明和应用 A 的证明，得到 B 的证明。

- **η-归约**（用于蕴含引入）：
  ```
  λx. M x  ⟶  M  (当 x 不在 M 中自由出现)
  ```

### 6.3 子公式性质

**子公式性质（Subformula Property）**：在正规化的证明中，所有出现的公式都是原结论的子公式。

这一性质的重要性：
1. 证明检查的有限性
2. 证明搜索的空间限制
3. 证明论的语义解释

### 6.4 Normalization 类

```python
class Normalization:
    """证明项的正规化"""
    
    @staticmethod
    def normalize(proof_term: str) -> str:
        """正规化证明项（简化）"""
        return proof_term
    
    @staticmethod
    def is_normal(form: str) -> bool:
        """检查公式是否处于正规形式（简化）"""
        return True
```

### 6.5 强正规化定理

**强正规化定理（Strong Normalization Theorem）**：所有合法证明项的归约序列都**必然终止**。这保证了自然演绎系统不会产生无限循环。

## 7. 希尔伯特系统与公理模式

### 7.1 希尔伯特系统的结构

希尔伯特系统（Hilbert System）是一种古老的证明系统，由以下部分组成：

1. **公理模式**：一组无需证明的公式模式
2. **推理规则**：通常只有**分离规则（Modus Ponens）**：
   ```
   A → B    A
   ───────────  (MP)
       B
   ```

### 7.2 典型公理模式

希尔伯特系统常用的公理模式包括：

1. **恒等公理**: `A → A`
2. **蕴含前置词公理**: `(A → B) → ((C → A) → (C → B))`
3. **合取消去**: `A ∧ B → A`
4. **合取引入**: `A → (B → A ∧ B)`
5. **析取引入**: `A → A ∨ B`
6. **否定公理**: `¬A → (A → B)`

### 7.3 希尔伯特系统的特点

- **最小推理规则**：仅使用分离规则，从公理出发进行推导
- **公理模式**：通过模式而非具体公式来表达无穷多条公理
- **证明长度**：希尔伯特系统的证明往往比自然演绎更长
- **理论化**：便于研究理论的公理结构

### 7.4 希尔伯特系统与自然演绎的关系

两者在证明能力上是等价的（对于经典命题逻辑）：
- 从自然演绎的证明可以转换为希尔伯特系统的证明
- 从希尔伯特系统的证明可以转换为自然演绎的证明

## 8. 插值定理

### 8.1 插值定理的定义

**插值定理（Interpolation Theorem）** 是证明论的重要成果，由克雷格（Craig）首先证明：

> 设 `⊢ A → B`，并且 `A` 和 `B` 不是等价的重言式，则存在一个公式 `C`（称为插值公式），使得：
> 1. `⊢ A → C`
> 2. `⊢ C → B`
> 3. `C` 中的命题变量既出现在 `A` 中又出现在 `B` 中

### 8.2 插值公式的性质

插值公式 `C` 满足：
- **原子性条件**：C 中出现的原子命题变量同时出现在 A 和 B 中
- **中介作用**：C 在 A 和 B 之间建立逻辑桥梁
- **一致性保持**：插值公式的存在与理论的一致性相关

### 8.3 插值定理的应用

1. **定义消失定理**：用于证明某些概念不可定义
2. **一致性证明**：插值方法可用于证明理论间的一致性关系
3. **算法逻辑**：在自动定理证明中有重要应用
4. **模型论**：与模型紧致性定理相关

### 8.4 插值定理的变体

- **Craig 插值定理**：如上定义
- **Maehara 插值定理**：适用于直觉主义逻辑
- **Lyndon 插值定理**：插值公式在正负出现意义上保持性质
