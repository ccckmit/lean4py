## 1. ANOVA 單因素方差分析測試

### 測試內容

| 測試方法 | 測試目的 |
|---------|---------|
| `test_basic` | 驗證三組數據的基本 ANOVA 分析 |
| `test_no_difference` | 驗證組內變異數為零時的邊界情況 |
| `test_single_group` | 驗證單組數據的預設處理 |

### 數學原理

**單因素方差分析 (One-Way ANOVA)** 用於檢驗三個或更多獨立組的均值是否存在統計顯著差異。

**核心概念：**

- **F 統計量**：F = MSB / MSW
  - MSB (Mean Square Between)：組間均方
  - MSW (Mean Square Within)：組內均方

- **p 值**：用於判斷顯著性，p < 0.05 通常表示組間存在顯著差異

- **eta² (效應量)**：表示自變量解釋的變異比例

**測試數據分析：**

```python
groups = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
```

- 第1組：均值 = 2
- 第2組：均值 = 5
- 第3組：均值 = 8

組間變異明顯，F > 0 且 p 值在合理範圍內。

### 邊界情況

- **同均值組**：所有組值相同時，組內變異數為零，導致 F = ∞
- **單組**：無法進行方差分析，返回 F = 0.0, p = 1.0

## 2. Chi-Square 卡方檢定測試

### 測試內容

| 測試方法 | 測試目的 |
|---------|---------|
| `test_uniform` | 驗證均勻分布的擬合優度 |
| `test_non_uniform` | 驗證非均勻分布的檢定能力 |
| `test_empty` | 驗證空數據的處理 |

### 數學原理

**卡方擬合優度檢定 (Chi-Square Goodness of Fit Test)** 用於檢驗觀察頻率與期望頻率之間是否存在顯著差異。

**卡方統計量計算公式：**

$$\chi^2 = \sum_{i=1}^{n} \frac{(O_i - E_i)^2}{E_i}$$

其中：
- $O_i$：第 i 類的觀察頻率
- $E_i$：第 i 類的期望頻率

**測試數據分析：**

1. **均勻分布測試**：
   - 觀察值：[10, 10, 10, 10]
   - 每組頻率相同，與均勻分布假設一致
   - 預期結果：χ² ≈ 0, p > 0.05

2. **非均勻分布測試**：
   - 觀察值：[50, 10, 10, 10]
   - 期望值：[20, 20, 20, 20]
   - 計算：χ² = (50-20)²/20 + (10-20)²/20 + (10-20)²/20 + (10-20)²/20 = 40
   - 預期結果：χ² > 20, p < 0.05（顯著差異）

### 自由度

對於擬合優度檢定：
- 自由度 = 類別數 - 1 = 4 - 1 = 3
