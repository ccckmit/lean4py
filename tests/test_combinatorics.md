## 1. 鸽巢原理测试 (Pigeonhole Principle)

### 数学原理

**鸽巢原理**是组合数学中最基本的原则之一：如果将 $n+1$ 个物体放入 $n$ 个盒子，则至少有一个盒子包含至少两个物体。

### 测试用例说明

| 测试方法 | 测试内容 | 数学验证 |
|---------|---------|---------|
| `test_finite_pigeonhole` | 有限鸽巢原理 | 验证将5个元素分配到3个集合时的分配结果 |
| `test_strong_pigeonhole` | 强化鸽巢原理 | 验证 $n$ 个物体放入 $k$ 个盒子，至少一盒有 $r$ 个物体的条件 |
| `test_infinite_pigeonhole` | 无限鸽巢原理 | 验证无限集合在给定映射下的像集 |

**强化鸽巢原理**：若将 $n$ 个物体放入 $k$ 个盒子且每个盒子至多有 $r$ 个物体，则存在某个盒子至少有 $\lceil n/k \rceil$ 个物体。

## 2. 卡特兰数测试 (Catalan Number)

### 数学原理

**卡特兰数** $C_n$ 计数满足以下条件的序列数量：
- 序列长度为 $2n$
- 前缀和非负（任何前缀中右括号数不超过左括号数）

卡特兰数的显式公式为：
$$C_n = \frac{1}{n+1}\binom{2n}{n} = \frac{(2n)!}{n!(n+1)!}$$

### 测试用例说明

| 测试方法 | 期望值 | 数学含义 |
|---------|-------|---------|
| `test_catalan_0` | $C_0 = 1$ | 空序列 |
| `test_catalan_1` | $C_1 = 1$ | "()" |
| `test_catalan_2` | $C_2 = 2$ | "()()", "(())" |
| `test_catalan_3` | $C_3 = 5$ | 五种合法括号匹配 |
| `test_catalan_4` | $C_4 = 14$ | 十四种合法括号匹配 |
| `test_catalan_list` | $[1, 1, 2, 5, 14]$ | 前5个卡特兰数 |

### 常见应用

- 合法括号匹配序列
- 二叉树遍历方式
- Dyck路径计数

## 3. 贝尔数测试 (Bell Number)

### 数学原理

**贝尔数** $B_n$ 表示将 $n$ 个元素的集合划分为若干非空不相交子集的方法数（即划分数）。

递推公式：
$$B_{n+1} = \sum_{k=0}^{n} \binom{n}{k} B_k$$

### 测试用例说明

| 测试方法 | 期望值 | 数学含义 |
|---------|-------|---------|
| `test_bell_0` | $B_0 = 1$ | 空集的一种划分 |
| `test_bell_1` | $B_1 = 1$ | $\{\{1\}\}$ |
| `test_bell_2` | $B_2 = 2$ | $\{\{1,2\}\}, \{\{1\},\{2\}\}$ |
| `test_bell_3` | $B_3 = 5$ | 五种划分方式 |
| `test_bell_4` | $B_4 = 15$ | 十五种划分方式 |
| `test_bell_list` | $[1, 1, 2, 5]$ | 前4个贝尔数 |

## 4. Dyck词测试 (Dyck Word)

### 数学原理

**Dyck词**是由左括号 '(' 和右括号 ')' 组成的字符串，其中：
- 字符串长度为偶数
- 任何前缀中左括号数不少于右括号数
- 总左括号数等于总右括号数

等价于 Dyck路径：在坐标平面上，从 $(0,0)$ 出发，每步要么向上 $(1,1)$ 要么向下 $(1,-1)$，永不越过 $x$ 轴，最终回到 $x$ 轴的路径。

### 测试用例说明

```python
# 有效 Dyck 词
is_dyck('')      # True  - 空串
is_dyck('()')    # True  - 单对括号
is_dyck('(())')  # True  - 嵌套括号
is_dyck('()()')  # True  - 并列括号

# 无效 Dyck 词
is_dyck('(')     # False - 不完整
is_dyck(')(')    # False - 首位非法
is_dyck('(()')   # False - 前缀违反条件
```

## 5. 集合族测试 (Set Family)

### 数学原理

**集合族**（Set Family）是集合的集合，组合数学研究其相交性、反链等性质。

### 关键概念

| 概念 | 定义 | 测试验证 |
|-----|------|---------|
| **反链 (Antichain)** | 集合族中任意两个集合互不包含 | `is_antichain` |
| **相交 (Intersecting)** | 集合族中任意两集合有非空交集 | `is_intersecting` |
| **并集大小** | 集合族所有元素的并集基数 | `union_size` |

### 测试用例

```python
# 反链测试
[{1}, {2}, {3}]     # True - 互不包含
[{1}, {1, 2}]       # False - {1} ⊂ {1,2}

# 相交测试
[{1,2}, {1,3}]      # True - 均有元素1
[{1,2}, {3,4}]      # False - 无公共元素
```

## 6. 斯佩纳定理测试 (Sperner's Theorem)

### 数学原理

**斯佩纳定理**是组合学中关于反链大小的基本定理：

设 $\mathcal{F}$ 是 $[n] = \{1,2,\ldots,n\}$ 的子集构成的的反链，则：
$$|\mathcal{F}| \leq \binom{n}{\lfloor n/2 \rfloor}$$

等号成立当且仅当 $\mathcal{F}$ 由所有 $\lfloor n/2 \rfloor$ 元子集或所有 $\lceil n/2 \rceil$ 元子集构成（称为"中间层"）。

### 测试用例说明

| $n$ | 最大反链大小 $\binom{n}{\lfloor n/2 \rfloor}$ |
|-----|---------------------------------------------|
| 1   | $\binom{1}{0} = 1$ 或 $\binom{1}{1} = 1$ |
| 2   | $\binom{2}{1} = 2$ |
| 3   | $\binom{3}{1} = 3$ 或 $\binom{3}{2} = 3$ |
| 4   | $\binom{4}{2} = 6$ |

## 7. 霍尔婚姻定理测试 (Hall's Marriage Theorem)

### 数学原理

**霍尔婚姻定理**是组合匹配理论的基础定理：

设 $\{X_i\}$ 是一组有限集合，若对每个子集 $S \subseteq \{1,\ldots,n\}$ 都有：
$$\left| \bigcup_{i \in S} X_i \right| \geq |S|$$

则存在一个**完美匹配**，即从每个集合中选取一个代表元素，且各代表元素互不相同。

### 霍尔条件

对于 bridesides = $[X_1, X_2, \ldots, X_n]$，霍尔条件要求对所有 $k \in \{1,\ldots,n\}$，任意 $k$ 个新娘能选择的丈夫并集大小至少为 $k$。

### 测试用例

```python
# 霍尔条件满足
[{0, 1}, {0, 1}]  # 两个新娘都能选丈夫0或1
# 任意1个新娘可选 ≥1 个丈夫 ✓
# 2个新娘可选 ≥2 个丈夫（{0,1}） ✓

# 霍尔条件不满足
[{0}, {0}]  # 两个新娘都只能选丈夫0
# 2个新娘只可选1个丈夫（{0}） ✗
```

## 8. 二项式系数测试 (Binomial Coefficient)

### 数学原理

**二项式系数** $\binom{n}{k}$ 表示从 $n$ 个元素中选取 $k$ 个的组合数：
$$\binom{n}{k} = \frac{n!}{k!(n-k)!}$$

### 范德蒙恒等式 (Vandermonde's Identity)

$$\sum_{k=0}^{r} \binom{m}{k} \binom{n}{r-k} = \binom{m+n}{r}$$

### 二项式定理

$$(x+y)^n = \sum_{k=0}^{n} \binom{n}{k} x^{n-k} y^k$$

### 测试用例说明

| 测试 | 期望值 | 验证内容 |
|-----|-------|---------|
| $\binom{0}{0}$ | 1 | 空集选择 |
| $\binom{5}{2}$ | 10 | $\frac{5!}{2!3!} = 10$ |
| $\binom{5}{5}$ | 1 | 全选 |
| $\binom{5}{6}$ | 0 | 不合法选择 |
| Vandermonde | True | 验证 $\binom{3+2}{2} = \binom{3}{0}\binom{2}{2} + \binom{3}{1}\binom{2}{1} + \binom{3}{2}\binom{2}{0} = 1+6+3 = 10$ |
| 二项式定理 | $8.0$ | $(1+1)^3 = 8$ |

## 生成函数测试 (Generating Function)

### 数学原理

组合数学中，**生成函数**用于编码序列信息：

- **普通生成函数 (OGF)**: $A(x) = \sum_{n \geq 0} a_n x^n$
- **指数生成函数 (EGF)**: $A(x) = \sum_{n \geq 0} a_n \frac{x^n}{n!}$

卡特兰数的生成函数：
$$C(x) = \frac{1-\sqrt{1-4x}}{2x} = \sum_{n=0}^{\infty} \frac{1}{n+1}\binom{2n}{n} x^n$$

### 测试中的生成函数验证

1. **Dyck词生成**：生成所有长度为 $2n$ 的Dyck词，数量等于 $C_n$
2. **Catalan列表**：生成前 $n+1$ 个卡特兰数，验证生成函数系数
