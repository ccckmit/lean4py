# 統計學測試文檔 (v1.3 版本)

## 概述

本測試文件驗證 `lean4py.statistics` 模組中的非參數統計檢定方法，主要包括：
- Mann-Whitney U 檢定（雙樣本檢定）
- Kruskal-Wallis H 檢定（多樣本檢定）

---

## 1. Mann-Whitney U 檢定

### 1.1 數學原理

Mann-Whitney U 檢定（又稱 Wilcoxon rank-sum 檢定）是一種**非參數檢定**，用於判斷兩個獨立樣本是否來自同一分布。

**統計量計算：**

$$U = n_1 \cdot n_2 + \frac{n_1(n_1+1)}{2} - R_1$$

其中：
- $n_1, n_2$ 為兩組樣本大小
- $R_1$ 為第一組的秩和（rank sum）

**原假設 $H_0$：** 兩組樣本來自相同分布
**對立假設 $H_1$：** 兩組樣本來自不同分布

### 1.2 測試案例說明

| 測試案例 | 資料設定 | 預期結果 | 統計意義 |
|---------|---------|---------|---------|
| `test_basic` | x=[1,2,3,4,5], y=[6,7,8,9,10] | U=0, p<0.05 | 兩組完全分離，分布差異極顯著 |
| `test_same_median` | x=[5,5,5,5,5], y=[5,5,5,5,5] | p>0.05 | 兩組完全相同，無顯著差異 |

**test_basic 分析：**
- 當兩組資料完全分離（如一組全小於另一組）時，U = 0
- 此時 p 值趨近於 0，達到顯著水準

## 2. Kruskal-Wallis H 檢定

### 2.1 數學原理

Kruskal-Wallis H 檢定是 Mann-Whitney U 檢定的多組推廣，用於比較 **k 個獨立樣本**是否來自同一分布。

**統計量計算：**

$$H = \frac{12}{N(N+1)} \sum_{i=1}^{k} \frac{R_i^2}{n_i} - 3(N+1)$$

其中：
- $N = \sum n_i$ 為總樣本數
- $R_i$ 為第 $i$ 組的秩和
- $n_i$ 為第 $i$ 組的樣本大小

**原假設 $H_0$：** 所有 k 組樣本來自相同分布
**對立假稱 $H_1$：** 至少有一組與其他組不同

### 2.2 測試案例說明

| 測試案例 | 資料設定 | 預期結果 | 統計意義 |
|---------|---------|---------|---------|
| `test_basic` | groups=[[1,2,3],[4,5,6],[7,8,9]] | H>0, p<0.05 | 三組遞增，分布差異顯著 |
| `test_same_values` | groups=[[5,5,5],[5,5,5],[5,5,5]] | H=0 或 p>0.05 | 三組完全相同，無差異 |

**test_basic 分析：**
- 三組資料有明確的遞進關係：[1,2,3] < [4,5,6] < [7,8,9]
- 這種分離度會產生大的 H 值，使 p < 0.05

---

## 3. 非參數檢定的優點

| 特點 | 說明 |
|-----|------|
| 不需假設常態分布 | 適用於順序資料或偏態資料 |
| 對離群值較穩健 | 使用秩次而非原始數值 |
| 適用於小樣本 | 當樣本量不足時仍可使用 |

---

## 4. 顯著水準判斷

檢定結果的判斷標準：

- **p < 0.05**：在 5% 顯著水準下拒絕 $H_0$，認為存在統計顯著差異
- **p ≥ 0.05**：無法拒絕 $H_0$，認為無統計顯著差異

## 5. 函數 API

### mann_whitney_u(x, y)

```python
def mann_whitney_u(x: list, y: list) -> tuple[float, float]
```

**參數：**
- `x`: 第一組樣本資料
- `y`: 第二組樣本資料

**回傳：**
- `U`: Mann-Whitney U 統計量
- `p`: 漸近 p 值

### kruskal_wallis(groups)

```python
def kruskal_wallis(groups: list[list]) -> tuple[float, float]
```

**參數：**
- `groups`: 多組樣本資料的列表

**回傳：**
- `H`: Kruskal-Wallis H 統計量
- `p`: 漸近 p 值
