# test_pde_v14.py 測試文件說明

## 概述

本測試文件驗證 `lean4py.pde` 模組中**拉普拉斯方程 (Laplace Equation)** 和**泊松方程 (Poisson Equation)** 數值求解器的正確性。

## 數學原理

### 拉普拉斯方程 (Laplace Equation)

**定義：**
```
∇²u = 0
```

在二維笛卡爾坐標下：
```
∂²u/∂x² + ∂²u/∂y² = 0
```

**物理意義：**
- 穩態熱傳導
- 靜電場電勢
- 不可壓縮流體的勢流

**邊界條件：**
- 狄利克雷邊界：u 在邊界上已知
- 諾依曼邊界：∂u/∂n 在邊界上已知

### 泊松方程 (Poisson Equation)

**定義：**
```
∇²u = f(x, y)
```

在二維笛卡爾坐標下：
```
∂²u/∂x² + ∂²u/∂y² = f(x, y)
```

**物理意義：**
- 有源穩態熱傳導（f 為熱源）
- 靜電學中的泊松方程（f 與電荷密度成正比）

### 數值方法：有限差分法

使用五點差分格式離散化：

```
∂²u/∂x² ≈ (u_{i+1,j} - 2u_{i,j} + u_{i-1,j}) / Δx²
∂²u/∂y² ≈ (u_{i,j+1} - 2u_{i,j} + u_{i,j-1}) / Δy²
```

代入得離散方程：
```
u_{i,j} = (u_{i+1,j} + u_{i-1,j} + u_{i,j+1} + u_{i,j-1}) / 4
```

這是**雅可比迭代法**的核心公式。

## 測試案例分析

### TestLaplaceEquation

#### `test_zero_solution`

**配置：**
- 區域：Lx = 1.0, Ly = 1.0
- 網格：nx = 20, ny = 20
- 邊界條件：預設為零（齊次邊界）
- 最大迭代次數：100

**期望結果：**
由於邊界條件全部為零，拉普拉斯方程的解在內部也應處處為零（唯一性定理）。

**驗證：**
所有內部網格點的值 |u| < 0.1

### TestPoissonEquation

#### `test_constant_source`

**配置：**
- 源項：f(x, y) = 1.0（常數源）
- 區域：Lx = 1.0, Ly = 1.0
- 網格：nx = 20, ny = 20
- 最大迭代次數：100

**期望結果：**
由於源項為正，泊松方程的解應該非負。

**驗證：**
所有網格點的值 u ≥ -0.1（考慮數值誤差的容許範圍）
