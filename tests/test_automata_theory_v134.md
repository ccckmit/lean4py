# 自動機理論測試文檔 (test_automata_theory_v134)

## 概述

本測試模組驗證 `automata_theory_v134.py` 中實現的自動機理論核心概念，包括確定性有限自動機 (DFA)、非確定性有限自動機 (NFA)、下推自動機 (PDA) 和圖靈機 (Turing Machine)。

---

## 1. DFA 測試 (確定性有限自動機)

### 數學定義
DFA 被定義為五元組 **M = (Q, Σ, δ, q₀, F)**，其中：
- **Q**: 有限狀態集合
- **Σ**: 輸入字母表
- **δ: Q × Σ → Q**: 確定性轉移函數
- **q₀ ∈ Q**: 初始狀態
- **F ⊆ Q**: 接受狀態集合

### 測試項目

| 測試方法 | 驗證內容 |
|---------|---------|
| `test_creation` | DFA 對象能夠正確創建，包含狀態集、字母表、轉移函數、初態和接受態 |
| `test_accepts` | DFA 能夠判斷字符串是否被接受 |
| `test_is_deterministic` | 驗證自動機的確定性特性 |

### 測試代碼解析
```python
dfa = DFA(["q0", "q1"], ["a"], {}, "q0", ["q1"])
```
此 DFA 具有：
- 狀態集 Q = {q0, q1}
- 字母表 Σ = {a}
- 空轉移函數 (簡化實現)
- 初始狀態 q0
- 接受狀態集 F = {q1}

## 2. NFA 測試 (非確定性有限自動機)

### 數學定義
NFA 同樣定義為五元組 **M = (Q, Σ, δ, q₀, F)**，但轉移函數不同：
- **δ: Q × Σ → P(Q)**: 轉移函數的輸出是狀態的冪集（可返回多個可能狀態）

### NFA 與 DFA 的關鍵區別
1. **非確定性**: 從同一狀態對同一輸入可以轉移到多個不同狀態
2. **空轉移**: 可能存在 ε-轉移（不消耗輸入字符的轉移）
3. **接受條件**: 存在至少一條接受路徑即可接受輸入

### 測試項目

| 測試方法 | 驗證內容 |
|---------|---------|
| `test_creation` | NFA 對象能夠正確創建 |
| `test_accepts` | NFA 能夠判斷字符串是否被接受 |
| `test_to_dfa` | NFA 可以轉換為等價的 DFA（子集構造法） |

### 子集構造法 (Powerset Construction)
NFA 轉 DFA 的核心算法：
1. DFA 的每個狀態對應 NFA 狀態集合的某個子集
2. 初始狀態為包含 NFA 初始狀態的集合
3. 轉移函數計算每個子集對所有輸入的閉包

## 3. PDA 測試 (下推自動機)

### 數學定義
PDA 定義為七元組 **M = (Q, Σ, Γ, δ, q₀, Z₀, F)**，其中額外包括：
- **Γ**: 棧字母表
- **Z₀ ∈ Γ**: 初始棧符號
- **δ: Q × (Σ ∪ {ε}) × Γ → P(Q × Γ*)**: 轉移函數

### PDA 與 FA 的關鍵區別
- **無限內存**: 使用棧（stack）來存儲信息
- **上下文無關文法**: 可以識別非正規語言（如 {aⁿbⁿ | n ≥ 0})
- **確定性 vs 非確定性**: DPDA 和 NPDA 是不同的類

### 測試項目

| 測試方法 | 驗證內容 |
|---------|---------|
| `test_is_deterministic` | 判斷 PDA 是否為確定性的 |
| `test_accepts` | 判斷 PDA 是否接受給定字符串 |

### 確定性 PDA (DPDA) 的條件
1. 對於每個狀態 q、棧頂符號 Z 和輸入 a，最多有一條轉移
2. 如果存在 ε-轉移，則不能有其他從該狀態的轉移
3. 轉移函數的確定性確保唯一計算路徑

## 4. 圖靈機測試

### 數學定義
圖靈機定義為七元組 **M = (Q, Σ, Γ, δ, q₀, q_accept, q_reject)**，其中：
- **Γ**: 帶字母表（包含空白符號 □）
- **q_accept, q_reject ∈ Q**: 接受和拒絕狀態
- **δ: Q × Γ → Q × Γ × {L, R}**: 轉移函數

### 圖靈機的核心特性
1. **停機問題**: 圖靈機是否會停機是不可判定的
2. **通用性**: 通用圖靈機可以模擬任何其他圖靈機
3. **Church-Turing 論題**: 直覺可計算函數與圖靈機計算函數等價

### 測試項目

| 測試方法 | 驗證內容 |
|---------|---------|
| `test_halts` | 判斷圖靈機是否在給定輸入上停機 |
| `test_is_universal` | 判斷圖靈機是否為通用圖靈機 |

### 通用圖靈機 (Universal Turing Machine)
- 能夠接受任何其他圖靈機的編碼表示
- 能夠模擬該圖靈機在任意輸入上的行為
- 這是現代計算機的理論原型

## 測試與數學性質的對應關係

```
automata_theory 模組結構:

DFA ──────────── 正規語言 (Regular Languages)
  │               ├─ 狀態有限性
  │               ├─ 確定性轉移
  │               └─ 應用: 詞法分析、模式匹配
  │
NFA ──────────── 與 DFA 等價（子集構造）
  │               ├─ 非確定性
  │               ├─ 更直觀的構造
  │               └─ 應用: 正則表達式實現
  │
PDA ──────────── 上下文無關語言 (CFL)
  │               ├─ 棧內存
  │               ├─ 確定性/非確定性區分
  │               └─ 應用: 語法分析
  │
TuringMachine ── 圖靈可判定/可枚舉語言
                  ├─ 停機問題不可判定
                  ├─ 通用計算
                  └─ 應用: 通用編程語言模型
```

## 形式語言層次 (Chomsky 層次)

| 類型 | 自動機模型 | 文法 | 語言類 |
|------|-----------|------|--------|
| Type-3 | DFA/NFA | 正規文法 | 正規語言 |
| Type-2 | PDA | 上下文無關文法 | CFL |
| Type-1 | 線性界限自動機 | 上下文相關文法 | CSL |
| Type-0 | 圖靈機 | 任意文法 | 遞歸枚舉語言 |
