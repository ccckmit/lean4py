# 卡爾曼濾波測試文檔

## 概述

本測試文件驗證 `lean4py.kalman_filter` 模組中卡爾曼濾波器（Kalman Filter）和卡爾曼平滑器（Kalman Smoother）的核心功能。

卡爾曼濾波器適用於線性高斯狀態空間模型，通過預測（Prediction）和更新（Update）兩個步驟遞歸估計系統狀態。

---

## 1. 卡爾曼濾波器測試 (`TestKalmanFilter`)

### 1.1 初始化測試 (`test_initialization`)

**測試內容：**
```python
kf = KalmanFilter(state_dim=2, obs_dim=2)
```

**數學原理：**

卡爾曼濾波器初始化時需要指定：
- `state_dim`: 狀態向量維度 (n)
- `obs_dim`: 觀測向量維度 (m)

初始化後的狀態包括：
- **狀態向量** x ∈ ℝⁿ：初始估計值 x₀（預設為零向量）
- **誤差協方差矩陣** P ∈ ℝⁿˣⁿ：初始估計不確定性（預設為單位矩陣）

協方差矩陣 P 表示狀態估計的誤差程度，對角線元素為各狀態分量的方差。

---

### 1.2 預測步驟測試 (`test_predict`)

**測試內容：**
```python
kf.F = [[1.0, 1.0], [0.0, 1.0]]  # 恆速模型
x_pred = kf.predict()
```

**數學原理：**

預測步驟基於狀態轉移模型：
```
x_{t|t-1} = F · x_{t-1|t-1}
```

其中：
- F 為狀態轉移矩陣（本例為恆速模型）
- x_{t|t-1} 為给定過去觀測到 t-1 時刻的條件下，t 時刻的預測狀態

同時更新協方差矩陣：
```
P_{t|t-1} = F · P_{t-1|t-1} · Fᵀ + Q
```

其中 Q 為過程噪聲協方差矩陣。

**恆速模型物理意義：**
```
[position]   [1  Δt] [position]
[velocity] = [0  1 ] [velocity]
```

Δt = 1 時，速度保持不變，位置增加當前速度值。

---

### 1.3 更新步驟測試 (`test_update`)

**測試內容：**
```python
kf.H = [[1.0, 0.0], [0.0, 1.0]]  # 單位觀測矩陣
z = [1.0, 2.0]
x_updated = kf.update(z)
```

**數學原理：**

更新步驟incorporate觀測值 z：

**創新向量（新息）：**
```
y = z - H · x_{t|t-1}
```

表示觀測值與預測觀測值之間的差異。

**創新協方差：**
```
S = H · P_{t|t-1} · Hᵀ + R
```

其中 R 為觀測噪聲協方差矩陣。

**卡爾曼增益：**
```
K = P_{t|t-1} · Hᵀ · S⁻¹
```

卡爾曼增益 K 權衡預測狀態和觀測信息的重要性。

**狀態更新：**
```
x_{t|t} = x_{t|t-1} + K · y
```

**協方差更新（Joseph形式）：**
```
P_{t|t} = (I - K · H) · P_{t|t-1}
```

當 H 為單位矩陣時，表示直接觀測到所有狀態分量。

---

### 1.4 預測-更新循環測試 (`test_predict_update_cycle`)

**測試內容：**
```python
kf.predict()
kf.update([1.0, 2.0])
```

**數學原理：**

卡爾曼濾波器正常工作時需要交替執行預測和更新步驟：

```
for each timestep t:
    predict:  x_{t|t-1}, P_{t|t-1} = f(x_{t-1|t-1}, P_{t-1|t-1})
    update:   x_{t|t}, P_{t|t} = g(x_{t|t-1}, P_{t|t-1}, z_t)
```

這確保每個時刻的狀態估計都同時利用了系統動態模型和觀測數據。

## 2. 卡爾曼平滑器測試 (`TestKalmanSmooth`)

### 2.1 RTS 平滑算法

卡爾曼平滑器使用 Rauch-Tung-Striebel (RTS) 算法，屬於**固定區間平滑**（Fixed-Interval Smoothing）。

**數學原理：**

RTS 平滑器從時間序列末端向前遞推，利用「未來」信息改善「過去」的狀態估計。

**平滑增益：**
```
G_t = P_t · Fᵀ · P_{t+1|t}⁻¹
```

**平滑狀態：**
```
x_{t|T} = x_{t|t} + G_t · (x_{t+1|T} - x_{t+1|t})
```

**平滑協方差：**
```
P_{t|T} = P_{t|t} + G_t · (P_{t+1|T} - P_{t+1|t}) · G_tᵀ
```

其中：
- x_{t|T} 為给定所有觀測到 T 時刻的條件下，t 時刻的平滑狀態
- P_{t|T} 為對應的平滑協方差

### 2.2 小序列平滑測試 (`test_smooth_small_sequence`)

**測試內容：**
```python
xs = [[1.0, 2.0], [1.1, 2.1], [1.2, 2.2]]
Ps = [[[0.1, 0.0], [0.0, 0.1]] for _ in range(3)]
F = [[1.0, 0.0], [0.0, 1.0]]  # 恆定狀態模型
smoothed_xs, smoothed_Ps = kalman_smooth(xs, Ps, F)
```

**數學意義：**

當 F 為單位矩陣時，系統狀態在時間上不變（恆定模型）。此時 RTS 平滑器會對序列中的狀態進行「平均化」處理，減少噪聲影響。

平滑後的估計比任何單個濾波估計都更準確，因為平滑器利用了全局信息。

### 2.3 空輸入測試 (`test_empty_input`)

**測試內容：**
```python
smoothed_xs, smoothed_Ps = kalman_smooth([], [], [[1.0]])
```

**數學意義：**

空序列輸入應返回空輸出，保持 API 的一致性，避免後續處理時出錯。

## 3. 矩陣維度對照表

| 符號 | 維度 | 說明 |
|------|------|------|
| x | n × 1 | 狀態向量 |
| P | n × n | 狀態協方差矩陣 |
| F | n × n | 狀態轉移矩陣 |
| Q | n × n | 過程噪聲協方差 |
| z | m × 1 | 觀測向量 |
| H | m × n | 觀測矩陣 |
| R | m × m | 觀測噪聲協方差 |
| K | n × m | 卡爾曼增益 |
| S | m × m | 創新協方差 |

## 5. 關鍵公式速覽

**預測步驟：**
```
x̂_{t|t-1} = F · x̂_{t-1|t-1}
P_{t|t-1} = F · P_{t-1|t-1} · Fᵀ + Q
```

**更新步驟：**
```
ŷ = z - H · x̂_{t|t-1}
S = H · P_{t|t-1} · Hᵀ + R
K = P_{t|t-1} · Hᵀ · S⁻¹
x̂_{t|t} = x̂_{t|t-1} + K · ŷ
P_{t|t} = (I - K · H) · P_{t|t-1}
```

**RTS 平滑（向後遞推）：**
```
Ĝ_t = P_t · Fᵀ · P_{t+1|t}⁻¹
x̂_{t|T} = x̂_{t|t} + Ĝ_t · (x̂_{t+1|T} - F · x̂_{t|t})
P_{t|T} = P_{t|t} + Ĝ_t · (P_{t+1|T} - P_{t+1|t}) · Ĝ_tᵀ
```
