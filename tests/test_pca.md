# PCA 测试文档

本文档解释 `test_pca.py` 中测试用例的数学原理。

## 1. PCA 概述

主成分分析（Principal Component Analysis，PCA）是一种经典的降维算法，通过正交变换将相关变量转换为线性不相关的主成分。

## 2. 测试用例详解

### 2.1 PCA 功能测试（TestPCA 类）

#### test_simple_2d_data（二维数据测试）

**数学原理：**

- 测试数据 `[1,1], [2,2], [3,3], [4,4]` 位于 y=x 直线上
- 这种数据具有**完美相关性**，所有方差集中在单一方向
- PCA 应识别出第一主成分捕获绝大部分方差

**验证内容：**

```python
assert variance[0] > variance[1]  # 第一主成分方差大于第二主成分
```

当数据高度相关时，第一特征值（方差）应远大于第二特征值。

#### test_dimensionality_reduction（降维测试）

**数学原理：**

- 输入数据 `[1,0,0], [2,0,0], [3,0,0]` 只在 x 轴方向有方差
- y 轴和 z 轴方向方差为 0
- 从 3D 降至 2D 时，有效信息不丢失

**验证内容：**

```python
assert len(transformed[0]) == 2  # 输出为 2 维
```

降维后数据维度等于 `n_components` 参数指定值。

#### test_empty_data（空数据处理）

**数学原理：**

- 空数据集的协方差矩阵为空矩阵
- 特征值分解和变换结果均为空列表

#### test_single_component（单主成分提取）

**数学原理：**

- 从 10 个点 `[i, i]`（i=0,...,9）中提取 1 个主成分
- 第一主成分捕获所有方差

### 2.2 协方差矩阵测试（TestCovarianceMatrix 类）

#### test_identity_covariance（不相关数据测试）

**数学原理：**

对于二维不相关数据，协方差矩阵为对角形式：

```
Σ = [σ²₁   0  ]
    [ 0   σ²₂  ]
```

**测试数据：**

```
[0,0], [1,0], [0,1], [1,1]
```

**数学验证：**

- `cov[0][1]`（非对角元素）应接近 0，因为 x 和 y 方向不相关
- x 和 y 方向的方差分别为正值

#### test_perfect_correlation（完美相关数据测试）

**数学原理：**

完美相关数据满足 `y = x`，协方差矩阵为：

```
Σ = [σ²  σ²]
    [σ²  σ²]
```

**数学验证：**

```python
assert abs(cov[0][1] - cov[0][0]) < 0.1  # 非对角 = 对角
```

当两个变量完美相关时，协方差矩阵的所有元素相等。

## 3. 核心数学概念

### 3.1 协方差矩阵

对于 n 维数据，协方差矩阵定义为：

```
Σᵢⱼ = Cov(Xᵢ, Xⱼ) = E[(Xᵢ - μᵢ)(Xⱼ - μⱼ)]
```

- 对角线元素：各变量的方差
- 非对角线元素：变量间的协方差

### 3.2 特征值分解

PCA 通过对协方差矩阵进行特征值分解：

```
Σ = VΛVᵀ
```

其中：
- Λ = diag(λ₁, λ₂, ..., λₙ) 是特征值矩阵（方差）
- V 是特征向量矩阵（主成分方向）

### 3.3 主成分的性质

1. **正交性**：主成分之间两两正交
2. **方差最大化**：第 i 个主成分捕获第 i 大的方差
3. **降维效率**：前 k 个主成分保留大部分信息
