# 測試文件：ml_clustering.py

## 概述

本測試文件驗證聚類（clustering）算法的正確性，特別是 **K-means** 算法的實現。測試案例涵蓋了基本功能、邊界條件和算法收敛性。

---

## 1. 測試驗證的內容

### 1.1 聚類算法的核心功能

- **簇分配正確性**：每個數據點必須被分配到有效的簇（標籤為 0 到 k-1）
- **簇中心計算**： centroids 數量應等於 k 值
- **標籤一致性**：返回的標籤數組長度應與輸入數據長度一致

### 1.2 K-means 算法數學原理

K-means 是一種 **迭代優化** 算法，目標是最小化簇內平方誤差（Inertia）：

$$J = \sum_{i=1}^{k} \sum_{x \in C_i} \|x - \mu_i\|^2$$

其中：
- $C_i$ 是第 i 個簇
- $\mu_i$ 是第 i 個簇的中心點
- \|x - \mu_i\|^2 是歐氏距離的平方

## 2. K-means 測試詳解

### 2.1 test_simple_clusters（簡單分離簇測試）

**測試內容**：在二維空間中創建兩個明顯分離的簇

**測試數據**：
- 簇 1：`(0,0)`, `(0.5,0.5)`, `(1.0,1.0)`
- 簇 2：`(10,10)`, `(10.5,10.5)`, `(11,11)`

**驗證內容**：
- `len(centroids) == 2`：返回兩個簇中心
- `len(labels) == len(data)`：標籤數量與數據點數量一致
- `all(l in [0, 1] for l in labels)`：所有標籤都在有效範圍內

**數學意義**：當簇中心距離足夠大時，算法應能正確區分不同的簇。

---

### 2.2 test_perfect_separation（完美分離測試）

**測試內容**：驗證算法在簇完全分離時的行為

**測試數據**：`[0.0], [1.0], [100.0], [101.0]`（k=2）

**驗證內容**：
- `labels[0] == labels[1]`：距離近的點被分到同一簇
- `labels[2] == labels[3]`：距離近的點被分到同一簇
- `labels[0] != labels[2]`：距離遠的點被分到不同簇

**數學意義**：利用歐氏距離公式驗證算法：

$$d(a,b) = \sqrt{\sum_{i=1}^{n}(a_i - b_i)^2}$$

當 d(0,1) << d(0,100) 時，算法應正確識別聚類結構。

---

### 2.3 test_single_cluster（單簇測試）

**測試內容**：k=1 時的邊界條件

**測試數據**：10 個均勻分佈的點 `[0.0], [0.1], [0.2], ..., [0.9]`

**驗證內容**：
- `len(centroids) == 1`：只有一個簇中心
- `all(l == 0 for l in labels)`：所有點的標籤都為 0

**數學意義**：當 k=1 時，簇中心即為所有數據點的均值（質心）：

$$\mu = \frac{1}{n}\sum_{i=1}^{n}x_i$$

---

### 2.4 test_empty_data（空數據測試）

**測試內容**：輸入空列表時的行為

**驗證內容**：
- `centroids == []`：返回空列表
- `labels == []`：返回空標籤

**數學意義**：空數據無法計算距離或均值，算法應正確處理並返回空結果。

---

### 2.5 test_k_equals_n（k等於數據點數測試）

**測試內容**：當簇數量等於數據點數量時

**測試數據**：`[0.0], [1.0], [2.0]`（k=3）

**驗證內容**：
- `len(centroids) == k`：每個點都是一個簇中心
- `len(labels) == len(data)`：標籤數量正確

**數學意義**：每個簇只有一個點，簇中心就是該點本身，inertia 為 0。

---

## 3. 算法實現要點

### 3.1 初始化策略

採用 **隨機初始化**（Random Initialization）：從數據點中隨機選擇 k 個點作為初始簇中心。

### 3.2 迭代過程

```
重複 n_init 次：
    1. 初始化 centroids
    2. 迭代直到收斂或達到 max_iter：
       a. 分配階段：將每個點分配給最近的簇中心
       b. 更新階段：重新計算每個簇的均值
    3. 選擇 inertia 最小的結果
```

### 3.3 收斂條件

當標籤不再發生變化時，算法收斂：

$$labels^{(t+1)} = labels^{(t)}$$
