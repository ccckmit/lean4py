# test_real_analysis_v12.md

## 測試概述

此測試檔案驗證 `lean4py.real_analysis` 模組中 `adaptive_simpson`（自適應辛普森積分法）函數的正確性。

---

## 1. 測試驗證的實分析內容

### 1.1 自適應辛普森積分法 (Adaptive Simpson's Method)

**數學原理：**

辛普森法則是一種數值積分方法，透過拋物線近似來估計定積分。對於區間 $[a, b]$，基本辛普森公式為：

$$\int_a^b f(x)\,dx \approx \frac{b-a}{6} \left[ f(a) + 4f\left(\frac{a+b}{2}\right) + f(b) \right]$$

**自適應機制**是指演算法根據函數的局部特性自動調整區間細分程度：
- 當某區間的近似誤差超過容許值時，該區間被二分
- 如此遞迴處理，直到所有子區間都滿足精度要求

**測試案例分析：**

| 測試 | 函數 | 積分區間 | 精確值 | 誤差容忍 |
|------|------|----------|--------|----------|
| `test_linear` | $f(x) = x$ | $[0, 1]$ | $\frac{1}{2}$ | $10^{-4}$ |
| `test_quadratic` | $f(x) = x^2$ | $[0, 1]$ | $\frac{1}{3}$ | $10^{-4}$ |
| `test_constant` | $f(x) = 5$ | $[0, 2]$ | $10$ | $10^{-4}$ |
| `test_sin` | $f(x) = \sin(x)$ | $[0, \pi]$ | $2$ | $10^{-3}$ |

## 2. 分析方法測試

### 2.1 線性函數積分測試

**測試內容：** 計算 $\int_0^1 x\,dx$

**解析解：**
$$\int_0^1 x\,dx = \left[ \frac{x^2}{2} \right]_0^1 = \frac{1}{2}$$

**數值方法收斂性：** 辛普森法對多項式精度較高，因為拋物線能完美逼近二次函數。

### 2.2 二次函數積分測試

**測試內容：** 計算 $\int_0^1 x^2\,dx$

**解析解：**
$$\int_0^1 x^2\,dx = \left[ \frac{x^3}{3} \right]_0^1 = \frac{1}{3}$$

### 2.3 常數函數積分測試

**測試內容：** 計算 $\int_0^2 5\,dx$

**解析解：**
$$\int_0^2 5\,dx = 5 \times (2 - 0) = 10$$

此測試驗證演算法對常數函數的處理，常數函數的積分應該退化为簡單的面積計算。

### 2.4 正弦函數積分測試

**測試內容：** 計算 $\int_0^\pi \sin(x)\,dx$

**解析解：**
$$\int_0^\pi \sin(x)\,dx = [-\cos(x)]_0^\pi = -\cos(\pi) - (-\cos(0)) = 2$$

**特點：** 正弦函數為非多項式超越函數，此測試確保自適應辛普森法能正確處理非代數函數。較寬的誤差容忍度 $\left(10^{-3}\right)$ 反映了超越函數積分的固有難度。

## 3. 測試設計原則

1. **精度要求分級**：多項式函數使用 $10^{-4}$，超越函數放寬至 $10^{-3}$
2. **覆蓋基本類型**：常數 → 一次 → 二次 → 超越函數
3. **驗證收斂性**：透過不同容許誤差（`tol=1e-6`）確保自適應機制正常運作
