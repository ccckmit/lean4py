## v1.20 实施计划

### 1. 新建 `differential_geometry.py` - 微分几何
- `Manifold` - 光滑流形
- `TangentSpace` / `TangentBundle` - 切空间与切丛
- `VectorField` - 向量场
- `Connection` - 仿射联络
- `RiemannianMetric` - 黎曼度量
- `Geodesic` - 测地线
- `CurvatureTensor` - 曲率张量
- `LeviCivitaConnection` - Levi-Civita联络

### 2. 新建 `two_category.py` - 2-范畴论
- `TwoCategory` - 2-范畴
- `Cat` - 范畴的范畴（2-范畴）
- `DoubleCategory` - 双重范畴
- `Bicategory` - 双范畴（弱2-范畴）
- `2Morphism` - 2-态射
- `AdjunctionIn2Category` - 2-范畴中的伴随
- `KanExtension2Category` - 2-范畴中的Kan扩张

### 3. 新建 `automata_theory.py` - 形式语言与自动机
- `DFA` / `NFA` - 确定/非确定有限自动机
- `RegularExpression` - 正则表达式
- `PushdownAutomaton` - 下推自动机
- `TuringMachine` - 图灵机
- `Grammar` - 形式文法
- `ChomskyHierarchy` - Chomsky层级
- `PumpingLemma` - 泵引理
- `KleeneStar` - Kleene星号

### 4. 扩展 `lie_groups.py` - 李群上的微分几何
- `LieGroup` 增加指数映射、伴随表示的微分
- `RiemannianSubmanifold` - 黎曼子流形
- `ConnectionOnPrincipalBundle` - 主丛上的联络
