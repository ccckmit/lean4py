# lean4py v1.10 Release Notes

## New Features

### Graph Neural Network (`gnn.py` - new module)
- `GCNLayer` - Graph Convolutional Network layer
- `GraphAttentionLayer` - Graph Attention layer
- `MessagePassing` - Base class for message passing GNNs
- `node_classification()` - Simple node classification with GN
- `graph_pooling()` - Graph pooling operations (mean, max, sum)

### Variational Inference (`variational_inference.py` - new module)
- `MeanFieldVI` - Mean Field Variational Inference
- `ELBO()` - Evidence Lower Bound computation
- `mean_field_update()` - Mean field coordinate ascent updates
- `variational_linear_regression()` - Bayesian linear regression with VI

### Information Retrieval (`information_retrieval.py` - new module)
- `TFIDF` - TF-IDF vectorizer
- `BM25` - Okapi BM25 ranker
- `cosine_similarity()` - Cosine similarity between vectors
- `retrieve()` - Simple document retrieval

### Recommendation System (`recommender.py` - new module)
- `UserItemMatrix` - User-item interaction matrix
- `collaborative_filtering()` - Item-based collaborative filtering
- `matrix_factorization()` - SVD-based matrix factorization
- `recommend()` - Generate recommendations for user
