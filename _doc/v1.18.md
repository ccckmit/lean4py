## v1.18 实施计划

### 1. 新建 `spectral_sequence.py`
- `SpectralSequence` - 通用谱序列 (E^2_{p,q} ⇒ H_n)
- `AdamsSpectralSequence` - Adams谱序列
- `SerreSpectralSequence` - Serre谱序列
- `Hypercohomology` - 超上同调
- `FilteredComplex` - 过滤复形

### 2. 新建 `topos.py`
- `Topos` - Topos基础
- `SheafTopos` - 层Topos

- `AbelianCategory` - 阿贝尔范畴
- `ProjectiveObject` / `InjectiveObject`
- `Generator` / `Cogenerator`
- `ExactFunctor`

### 3. 新建 `lie_algebra_classification.py`
- `DynkinDiagram` - Dynkin图分类
- `ClassificationTheorem` - 半单李代数分类定理
- `Weight` / `HighestWeightVector` - 权理论
- `WeylGroup` - Weyl群
- `VermaModule` - Verma模
- `KostantForm` - Kostant整数形式

### 4. 新建 `hopf_algebra.py`
- `Coalgebra` - 余代数
- `Bialgebra` - 双代数
- `HopfAlgebra` - Hopf代数
- `GroupAlgebra` - 群代数

- `ModuleAlgebra` / `InvariantTheory` - 表示论与不变量

### 5. 扩展 `sheaf.py`
- `SheafOfRings` - 环层
- `SheafOfModules` - 模层
- `Scheme` - 概形
- `SchemeMorphism` - 概形态射
- `Site` / `GrothendieckTopology` / `Coverage`
