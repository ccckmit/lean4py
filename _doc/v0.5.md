## P0 - 必须修复（全部完成）

### 1. ✅ 补上 `tests/test_nat.py`

**问题**: `nat.py` 模块完全没有测试。

**完成内容**:
- 创建 `tests/test_nat.py`（34 个测试用例）
- 测试 `Nat` 类构造和表示
- 测试 `zero`, `succ`, `pred`
- 测试 `nat_add`, `nat_mul`, `nat_sub`
- 测试 `nat_le`, `nat_lt`, `nat_eq` 比较运算
- 测试 `is_zero` 判断
- 测试运算符重载 (`+`, `*`, `-`, `<=`, `<`, `>=`, `>`)
- 测试 `NatInduction`

### 2. ✅ 修复 `sets.complement()`

**问题**: `sets.py:70-71` 返回原集合而非补集。

**完成内容**:
- 修改 `complement()` 接受通用集参数: `complement(s: Set, universe: Set) -> Set`
- 更新 `__invert__` 抛出异常提示新用法
- 更新 `tests/test_sets.py` 中的测试用例
- 更新 `examples/02_sets.py` 示例

### 3. ✅ 完成 `graph_clique()`

**问题**: `graph_theory.py:418-420` 函数体为空。

**完成内容**:
- 实现 Bron–Kerbosch 算法寻找最大团
- 添加 `test_graph_theory.py` 中的测试（通过现有测试覆盖）
- 导出到 `__init__.py`

### 4. ✅ 处理 numpy/scipy 依赖

**问题**: `probability.py` 使用了 `numpy` 和 `scipy.stats`，但未在 `pyproject.toml` 中声明。

**完成内容**:
- 在 `pyproject.toml` 添加可选依赖组：

- 在 `probability.py` 添加导入时的友好错误提示

## P1 - 重要改进（全部完成）

### 5. ✅ 为公开 API 添加 docstrings

**范围**: 所有 `lean4py/` 下的公开类和函数。

- `nat.py`: Nat, nat, zero, succ, pred, nat_add, nat_mul 等

### 6. ✅ 扩展 `linear_algebra.eigenvalues()`

**问题**: 当前仅支持 1x1 和 2x2 矩阵（解析解），更大矩阵返回错误。

**完成内容**:
- 使用 numpy 的 `np.linalg.eigvals` 处理一般矩阵
- 保持对 1x1 和 2x2 的纯 Python 实现（无 numpy 依赖时）
- 当 numpy 不可用时返回空列表（保持向后兼容）

### 7. ✅ 导出 `graph_clique` 到 `__init__.py`

**依赖**: P0 #3 完成后执行。

**完成内容**:
- 在 `lean4py/__init__.py` 中添加 `graph_clique` 导入
- 在 `__all__` 列表中添加 `"graph_clique"`
