# lean4py v1.9 Release Notes

## New Features

### Hidden Markov Model (`hmm.py` - new module)
- `HMM` - Hidden Markov Model class
- `forward_algorithm()` - Forward algorithm for likelihood computation
- `viterbi()` - Viterbi algorithm for most likely state sequence
- `baum_welch()` - Baum-Welch algorithm for parameter estimation

### Kalman Filter (`kalman_filter.py` - new module)
- `KalmanFilter` - Simple Kalman filter for linear systems
- `predict()` - Prediction step
- `update()` - Update step with observation
- `kalman_smooth()` - Rauch-Tung-Striebel smoother

### Sparse Coding (`sparse_coding.py` - new module)
- `sparse_coding()` - Learn sparse representation of data
- `OMP()` - Orthogonal Matching Pursuit for sparse approximation
- `compute_dictionary()` - Learn overcomplete dictionary

### Manifold Learning (`manifold_learning.py` - new module)
- `isomap()` - Isomap algorithm for nonlinear dimensionality reduction
- `LLE()` - Locally Linear Embedding
- `compute_geodesic_distances()` - Compute geodesic distances on manifold
