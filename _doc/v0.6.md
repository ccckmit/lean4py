```python
def symmetric_difference(a: Set, b: Set) -> Set:
    """返回两个集合的对称差 (A \ B) ∪ (B \ A)"""
    return union(difference(a, b), difference(b, a))
```

**测试**: 3 个测试用例（不相交、有重叠、相同集合）

### 2. ✅ `nat.factorial()` 和 `nat.fibonacci()`

```python
def factorial(n: Nat) -> Nat:
    """Return n! (n factorial)."""
    result = 1
    for i in range(2, n.n + 1):
        result *= i
    return Nat(result)

def fibonacci(n: Nat) -> Nat:
    """Return the nth Fibonacci number (0-indexed)."""
    if n.n <= 1:
        return n
    a, b = Nat(0), Nat(1)
    for _ in range(2, n.n + 1):
        a, b = b, Nat(a.n + b.n)
    return b
```

**测试**: 10 个测试用例（factorial: 0, 1, 5; fibonacci: 0, 1, 5, 10; gcd; is_prime; even; odd）
