- **Galois Theory**: Field extensions, Galois groups, solvability by radicals

## v1.27 实施计划

### 1. 新建 `algebraic_topology.py` - Algebraic topology
模仿 mathlib4 `Mathlib.Topology.Category.Top` 和 `Mathlib.AlgebraicTopology`

- `FundamentalGroup` - 基本群 π₁(X, x₀)
- `Homotopy` - 同伦等价、同伦类
- `SimplicialComplex` - 单纯复形
- `CWComplex` - CW 复形 (简化)
- `Homology` - 同调群 (简化)
- `BettiNumber` - Betti 数

### 2. 新建 `galois_theory.py` - Galois theory
模仿 mathlib4 `Mathlib.FieldTheory.Galois`

- `FieldExtension` - 域扩张 L/K
- `GaloisGroup` - Galois 群 Gal(L/K)
- `SeparableExtension` - 可分扩张
- `NormalExtension` - 正规扩张
- `GaloisExtension` - Galois 扩张
- `FundamentalTheorem` - Galois 基本定理 (陈述)
- `SolvabilityByRadicals` - 根式可解性

### 3. 新建 `representation_theory.py` - Representation theory
模仿 mathlib4 `Mathlib.RepresentationTheory`

- `Representation` - 表示 (G → GL(V))
- `Character` - 特征标 χ(g) = Tr(ρ(g))
- `IrreducibleRepresentation` - 不可约表示
- `MaschkeTheorem` - Maschke 定理 (半单性)
- `SchurLemma` - Schur 引理
- `Decomposition` - 完全可约性

### 4. 新建 `homological_algebra.py` - Homological algebra
模仿 mathlib4 `Mathlib.Algebra.Homology`

- `ChainComplex` - 链复形 ... → Cₙ₊₁ → Cₙ → Cₙ₋₁ → ...
- `BoundaryMap` - 边界算子 ∂ₙ: Cₙ → Cₙ₋₁
- `CycleGroup` - 闭链群 Zₙ = ker ∂ₙ
- `BoundaryGroup` - 边缘链群 Bₙ = im ∂ₙ₊₁
- `HomologyGroup` - 同调群 Hₙ = Zₙ/Bₙ
- `ExactSequence` - 正合序列
- `FiveLemma` - 五引理 (简化)
