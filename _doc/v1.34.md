## 背景与目标

模仿对象: [mathlib4](https://github.com/leanprover-community/mathlib4)

mathlib4 核心覆盖领域（截至 v4.29.1）:
- **Formal Languages**: Regular expressions, context-free grammars, Chomsky hierarchy
- **Automata Theory**: DFA, NFA, PDA, Turing machines
- **Computational Complexity**: P, NP, NP-completeness, reductions
- **Lambda Calculus**: Simply typed lambda calculus, β-reduction

lean4py 当前状态：
- v1.33 完成 Set theory advanced, Model theory, Proof theory, Type theory advanced
- 已有形式化逻辑基础（logic.py, proof_theory.py）
- 缺少形式语言、自动机、计算复杂性、λ演算

## v1.34 实施计划

### 1. 新建 `formal_languages.py` - Formal languages
模仿 mathlib4 `Mathlib.Computability.Language`

- `RegularLanguage` - 正则语言（正则表达式）
- `ContextFreeGrammar` - 上下文无关文法
- `ChomskyHierarchy` - Chomsky 层次结构
- `PumpingLemma` - 泵引理（陈述）

### 2. 新建 `automata_theory.py` - Automata theory
模仿 mathlib4 `Mathlib.Computability.Automaton`

- `DFA` - 确定有限自动机
- `NFA` - 非确定有限自动机
- `PushdownAutomaton` - 下推自动机
- `TuringMachine` - 图灵机（简化）

### 3. 新建 `computational_complexity.py` - Computational complexity
模仿 mathlib4 `Mathlib.Computability.Complexity`

- `ComplexityClass` - P, NP, PSPACE 等
- `NPCCompleteness` - NP 完全性
- `Reduction` - 多项式时间归约
- `CookLevin` - Cook-Levin 定理（陈述）

### 4. 新建 `lambda_calculus.py` - Lambda calculus
模仿 mathlib4 `Mathlib.Logic.LambdaCalculus`

- `LambdaTerm` - λ项
- `BetaReduction` - β-归约
- `SimplyTypedLambda` - 简单类型λ演算
- `ChurchNumerals` - Church 编码（简化）
