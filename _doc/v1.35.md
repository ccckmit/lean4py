## 背景与目标

模仿对象: [mathlib4](https://github.com/leanprover-community/mathlib4)

mathlib4 核心覆盖领域（截至 v4.29.1）:
- **Information Theory**: Entropy, mutual information, data compression
- **Coding Theory**: Error-correcting codes, Hamming distance, linear codes
- **Cryptography**: Public-key crypto, RSA, elliptic curve crypto
- **Quantum Computing**: Qubits, quantum gates, quantum algorithms (simplified)

lean4py 当前状态：
- v1.34 完成 Formal languages, Automata theory, Computational complexity, Lambda calculus
- 已有概率基础（probability.py, probability_enhanced.py）
- 缺少信息论、编码论、密码学、量子计算

## v1.35 实施计划

### 1. 新建 `information_theory.py` - Information theory
模仿 mathlib4 `Mathlib.ProbabilityTheory.InformationTheory`

- `Entropy` - 熵 H(X) = -Σ pᵢ log pᵢ
- `MutualInformation` - 互信息 I(X;Y)
- `DataCompression` - 数据压缩（简化）
- `ChannelCapacity` - 信道容量 C = max I(X;Y)（简化）

### 2. 新建 `coding_theory.py` - Coding theory
模仿 mathlib4 `Mathlib.AlgebraicGeometry.CodingTheory`

- `LinearCode` - 线性码 C ⊆ 𝔽ⁿ
- `HammingDistance` - Hamming 距离 d(x,y)
- `GeneratorMatrix` - 生成矩阵 G
- `ParityCheckMatrix` - 奇偶校验矩阵 H
- `MinimumDistance` - 最小距离 d(C)

### 3. 新建 `cryptography.py` - Cryptography
模仿 mathlib4 `Mathlib.Algebra.Cryptography`

- `RSACrypto` - RSA 公钥加密
- `EllipticCurveCrypto` - 椭圆曲线密码学（简化）
- `HashFunction` - 哈希函数（简化）
- `DigitalSignature` - 数字签名（简化）

### 4. 新建 `quantum_computing.py` - Quantum computing
模仿 mathlib4 `Mathlib.Quantum` (if exists) 或简化实现

- `Qubit` - Qubit |ψ⟩ = α|0⟩ + β|1⟩
- `QuantumGate` - 量子门（X, Y, Z, Hadamard）
- `QuantumCircuit` - 量子电路（简化）
- `DeutschAlgorithm` - Deutsch 算法（简化）
