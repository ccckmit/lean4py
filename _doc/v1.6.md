# lean4py v1.6 Release Notes

## New Features

### Machine Learning Advanced (`ml_basics.py` extended)
- `svm_linear()` - Linear Support Vector Machine using gradient descent
- `decision_tree()` - Basic decision tree for classification (CART-style)

### Neural Network (`neural_network.py` - new module)
- `DenseLayer` - Fully connected layer
- `NeuralNetwork` - Simple feedforward network
- `sigmoid()`, `relu()` - Activation functions
- `mse_loss()` - Mean squared error loss
- `train_neural_network()` - Basic training with backpropagation

### Bayesian Statistics (`bayesian.py` - new module)
- `BayesianModel` - Base class for Bayesian inference
- `GaussianPrior`, `BetaPrior` - Conjugate priors
- `posterior_update_normal()` - Update Gaussian posterior
- `posterior_update_beta_binomial()` - Update Beta-Binomial posterior
- `metropolis_hastings()` - MCMC sampling
- `bayesian_linear_regression()` - Bayesian linear regression

## Test Coverage
- `tests/test_ml_advanced.py` - 4 tests (SVM, decision tree)
- `tests/test_neural_network.py` - 4 tests (layers, network, training)
- `tests/test_bayesian.py` - 4 tests (priors, posterior, MCMC)
